# Does achieved tool displacement tell a frozen policy which part of its last plan to reuse?

Registered on November 24 before this workstream ran any new policy or simulator trajectories. The estimand is paired native BASE success after physical arm substitution at a common five-control inference cadence. A physical stall can put the end effector behind its intended translation. Reusing an earlier segment might help complete the movement, or repeat an obsolete action after contact. Equal or worse native success than ordinary temporal ensembling argues against using this detector. A change only against raw does not establish a phase benefit.

## Prior work and controls

Chi et al. align timestamped observations and schedule actions using measured execution delays. The present clock is measured displacement within one executed block. [UMI, policy interface PD1](https://arxiv.org/html/2402.10329)

Nie et al. use low-speed valleys of the proposed trajectory to choose when to query again. Here each condition makes one fresh policy query every five controls. [PACE, §3](https://arxiv.org/html/2606.00537v1)

Zhao et al. average overlapping predictions for the same time using exponential weights. Our fixed control uses exactly two consecutive chunks with equal weights and translation-only overlap. [ACT, §IV-C](https://arxiv.org/pdf/2304.13705)

Liu et al. use consistency with a prior chunk and contrast among candidate samples. Our intervention uses one frozen-policy draw per observation and reindexes the previous draw. [BID, §4](https://bid-robot.github.io/static/BID_paper.pdf)

The earlier factory measured source/target dynamics, fresh versus stale residual corrections, proposed-speed execution, and drawer-opening prompts. The separate timing worker estimates temporal response. Here there is no new reader fit, contact cue, target lag estimate, changed prompt, shortened inference interval or new control residual. The comparison against the fixed overlap isolates the choice of donor index. ## Frozen intervention

Store every original full decoded float32 H×7 proposal. The normal runner clips commands and applies its regular tuned inverse translation yaw and XYZ gain, plus gripper-sign correction. At each replan in fixed or progress, blend just the five new canonical XYZ commands with five canonical XYZ commands from the immediately preceding **original policy draw**, clipping each component of each input to the native bounds before averaging. Leave all other components and the proposal tail exactly as returned. Then route the result through the ordinary motor clipping/retargeting. Raw and tuned return the full original proposal. The first draw in all modes is unchanged. Fixed always uses previous indices [5,10). Progress uses [j,j+5); index j=0 reuses the opening. No history crosses resets. A terminal short chunk has no successor.

At the new query, the measured vector is the public metric TCP at the end of the previous five controls minus its TCP immediately before the first of those controls. Exclude absolute position. Rotate this local displacement by the same estimated yaw used by the tuned policy to obtain estimated source axes. Construct six prefix waypoints **of the original donor** in these axes. First route its first five commands through the exact inverse motor correction and clipping to obtain the would-be issued commands. Map each issued XYZ into estimated source axes using the tuned yaw and gain and apply native physical clipping (XYZ yaw in the plane, gain on all three axes). Apply this same forward estimate to the actual issued commands from the block preceding the donor, or zeros at episode opening. This handles both saturation and the inherited motion from the block that actually ran. The donor waypoint is counterfactual whenever the previous block was itself ensembled. The observed TCP came from the actual mixed commands. Both the original plan and actual sent commands are recorded, so these trajectories can be distinguished. Using the executed mixture as the donor would recursively blend old plans and change the comparison.

Use the existing source-only 6×3 row-vector regression from 192 nominal Panda/Sawyer 15-control traces on disjoint task identities. The first three rows A map the mean current XYZ over five controls to metres of endpoint displacement; the other three B map the preceding block mean. For candidate j, W(0)=0 and W(j)=(sum of the first j would-be source-frame commands) A / 5 + (j/5) × (preceding actual source-frame mean) B. This interpolates carryover uniformly inside a block. Its j=5 endpoint exactly recovers the published source law. Within-block accuracy and transfer under contact remain assumptions. Do not use the nominal truth to undo an erroneous tuned gain or yaw. Let j minimize Euclidean distance between achieved displacement and W(j), breaking exact ties in favor of the largest j. Freeze before CPU or native outcomes.
