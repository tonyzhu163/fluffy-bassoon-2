# Follow-up on moderate optical rolls

The quarter-turn experiment showed that the frozen reader's predicted yaw changed systematically with the camera. Before viewing any moderate-roll scores, test displayed-image rolls of 0°, ±15°, and ±30° on the same 96 supports and three-chunk budget. Use one fixed virtual focal length (zoom 1.40×) across these five conditions and bilinearly sample the source image in a single affine warp about its center. All output pixels must come from the real recorded image at every angle. Apply the same centered zoom and interpolation at 0° as the control. The moderate-roll baseline has a different field of view from the full-frame quarter-turn baseline. Use no calibration on target data. Report paired native yaw displacement and error relative to this experiment's 0° view. Measure the effects of interpolation by rotating back using a second resampling on a common interior field if feasible. A directional drift at both signs which increases with roll magnitude supports camera sensitivity at modest displacements. This is a follow-up on the same trajectories, not a new holdout.
