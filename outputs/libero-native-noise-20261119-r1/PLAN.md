# How much does sampling change a frozen π0.5 retry?

Use the 15 standard LIBERO-90 fitting tasks that had published all 20 repeats when the archive was listed. Task IDs are 0, 2, 3, 7, 10, 11, 13, 15, 17, 22, 23, 27, 29, 33 and 34. Include every repeat, 00 through 19. Each pair consists of two native rollouts from the same settled query pose with the same instruction. The collector assigns a separate random stream to each candidate and selects a candidate by an independent fair coin at each replan. The two rollouts are samples of the same frozen policy. [Collection interface](../libero90-full-action-20261119-r1/IO.md)

Measure wrist separation in centimetres at fixed physical control counts 1, 5, 25, 50 and 100. Report the median, 90th percentile and number of pairs for which both trajectories reached each time. Count pairs where both, exactly one, or neither succeed under native reward. Use the two stored proposals for the opening command comparison. Only the selected proposal has an observed physical trajectory within each rollout. Nearly coincident wrists and identical outcomes throughout would weaken the case for studying sampling as a source of useful alternatives. Divergence alone cannot establish that a reader can choose the better continuation.

The implementation worker prepares the archive measurement. A second worker inspects the interpretation and controls. Use the existing tapes on one Baige CPU, with zero new GPU-hours. Stop after measuring this fixed snapshot. Held-out tasks and prospective history-based choices require separate evaluation.
