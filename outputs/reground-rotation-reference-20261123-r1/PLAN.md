# Reproduce ReGround on the released 90° action-frame rotation

Can the released implementation recover the published frozen π₀.₅ rotation result, and how does the frozen single-attempt SymMeta reader perform on the same reference cases? The published ReGround test IQM for success is 0.98. Its unsafe-episode IQM is 0.29. Compare estimates and their uncertainty without inventing an agreement threshold. Report the frozen base control and identify differences in runtime, sampling and calibration costs. A failure to reproduce the reference limits any claim comparing methods.

Pin the authors’ [released code](https://github.com/umersiddique94/ReGround/tree/16a98486f560676b9036d1a6d067b9dd51a5917a) and use its rotation recipe, policy and observation preprocessing, task list, native horizons, 10-control policy cadence, noise generation, test starts 15–49, adaptation seeds 0–4 and published aggregation. Each reference method has 1,400 episode assignments across eight tasks. Preserve both the raw native successes and the published unsafe-episode metric. Record both the generated and used nominal and target adaptation data. Retain the released gate setting and record it. Freeze the accessible checkpoint revision and distinguish it from the authors’ unreported historical checkpoint hash.

Run the unmodified reference first and verify real simulator, inference and method behavior. Run the frozen seed-41 SymMeta adapter on the same test cases with one continuous attempt, only observations and issued commands available at the time of each update. Keep the target interface and native 90° perturbation exactly as released, including its effect on wrist rotation. Record the scope of SymMeta’s action correction, images, updates, reset and interaction costs. Pair by case and policy noise, and distinguish shared frozen-policy cases from independently fitted adaptation seeds.

Use Baige Distributed Training for GPU collection, fitting and evaluation. Begin with bounded resumable jobs and use measured throughput to decide allocation size. Across the two studies stay within the standing 50 GPU-hour budget unless the user authorizes an increment. The owners are the runtime and checkpoints worker, reference evaluator worker, matched SymMeta evaluator worker and coordination owner. Record each producing revision and all launch receipts here.
