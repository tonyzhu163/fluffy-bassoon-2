# Reference condition and published comparison

The authors report success IQMs of 0.00 for their frozen base policy and 0.98 for ReGround at 90° rotation, and unsafe-episode IQMs of 0.80 and 0.29. The release rotates both translational and angular action components on the native arm. The fitted inverse in SymMeta's original planar experiment corrects planar translation. The native reference comparison preserves the released action transform and records what each adapter actually corrects. [Paper, Table 1](https://arxiv.org/html/2611.20244v1#S4.T1) · [Released shift definition](https://github.com/umersiddique94/ReGround/blob/16a98486f560676b9036d1a6d067b9dd51a5917a/reground/envs/shifts.py#L70-L87)

The unmodified authors’ CLI generated the rotation schedule on Baige Linux. Each adaptation seed 0–4 has the same 280 task–start pairs. The eight tasks are spatial 0/2, object 1/3, goal 1/2 and long 1/3. Starts 15–49 are the test split. The policy replans after ten controls. The IQM trims the top and bottom quarter of the task-by-seed success rates. The full schedule contains 1,400 assignments per method and 280 unique task–start pairs. The released config uses the inverse-dynamics anchor and leaves the optional monitor disabled for this table row. [Generated assignment list](evidence/rotation-jobs.json.gz) · [Rotation configuration](https://github.com/umersiddique94/ReGround/blob/16a98486f560676b9036d1a6d067b9dd51a5917a/configs/paper.json) · [Gating and model construction](https://github.com/umersiddique94/ReGround/blob/16a98486f560676b9036d1a6d067b9dd51a5917a/reground/method/build.py)

The README’s headline reproduction collects 100,000 babbling and 100,000 policy-driven transitions per body and seed before fitting. The released fits consume a 100,000-transition nominal subset and a 10,000-transition target subset. On this cell the target fit takes 6,000 babbling transitions and 4,000 policy-driven transitions. These setup costs can be shared across many task episodes on one shifted deployment. Record the realized generation totals and the per-fit budgets separately.
