# Independent Sawyer supervision is available for one plate-pushing task

**Baige holds 506 distinct successful Sawyer teacher trajectories across 372 training layouts.** All are for LIBERO-Pro2.0 BASE `libero_goal/5`, “push the plate to the front of the stove.” One training trajectory now has a self-contained recording with both cameras, measured tool pose, both finger positions and a native terminal reward of 1. It yields 67 full ten-action examples. The primary Panda pilot selected LIBERO-Object and LIBERO-Spatial demonstrations. None of its eight training instructions appears in this Sawyer bank. ## One recording with the pilot's full inputs

The archive stores signed finger separation. The current stock OpenPI transform consumes both finger coordinates, and width alone cannot recover them. On the first generated training seed, 300000, I replayed the original Sawyer expert's exact controls from its archived sampled scene with cameras enabled and both finger sensors exposed. The scene fingerprint and compiled arm identity matched. The CPU run reached native success after 76 controls. On the archived collection host it took 77. The settled state hashes differed, and maximum tool-position separation over the common observations was 0.287 mm. Assigning each finger half the measured opening would have introduced up to 0.391 mm of error per finger. The new recording keeps observations, commands and rewards from the same execution. The remaining 505 trajectories have only the archived gripper representation verified here. [Native readback](evidence/replay.json) · [Pilot data contract](../data/API.md)

On Baige the sample is `/mowenjie/fluffy-bassoon-2/outputs/frozen-vla-cotraining-20261124-r1/source-diversity/cpu01/sawyer-300000.h5`. SHA-256 is `63296a7ff936b0ef90671f98267d19945451b9ef4b6cf7cddd174caa3cb98229`. Its five public observation arrays use the exact raw API keys. Each has 77 observations including the terminal one. Row `t` precedes `actions[t]`, and `rewards[t]` follows that control. The two views each contain 76 distinct pre-action frames. For `t=0…66`, pair observation `t` with `actions[t:t+10]` and the history available before action `t`. The pilot's actual `PublicHistory` constructed all 67 examples with four past-transition slots and matched every available issued action. ## What this identifies

Adding only the Sawyer bank to the existing Panda basket and bowl tasks would change the instruction, teacher and arm together. The 280 same-placement Panda/Sawyer positives provide a source-only comparison with common task and scene, including 253 generated layouts with the same scripted teacher family. The cameras still reveal the arm, the selected routes can differ, and every retained Sawyer gripper command was +1. Success on this plate push supplies evidence for closed-gripper contact and translation. It leaves grasp/release behavior, recovery from arbitrary policy errors, and the benefit of conditioning on history unresolved. Counts describe retained positive data. One successful replay establishes full-input feasibility on that start.

The registered fit and its scoring harness received no data or code changes from this check. No evaluation arm or reserved start was run. The independent Sawyer teacher made a Panda-human open-loop fallback unnecessary. Baige used CPU core 26 and zero GPU-hours. The native wrapper was pinned to `a8a997e7`, the replay script to `fb3bb94f`, the deduplicated inventory to `e5e01c19` and the history API to `97bedc86`.
