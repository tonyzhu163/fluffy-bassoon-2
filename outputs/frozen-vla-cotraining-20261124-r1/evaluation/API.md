# Evaluation interface

Use sibling data/source_data.PublicHistory and model/cotrain_policy.LockedPolicy as documented in their API files. The held-out identifiers are in PANEL.md. Reserve those released rows on shared tasks from all offline data, including source validation. Store the fit.json SHA in the root handoff from the completed source-only training run. The launcher takes the immutable fit directory and that digest separately.

LockedPolicy exposes its stock OpenPI Policy, parity(item, noise=noise), and digests() for the resident stock NNX tree, fitted arrays and normalization. The recovered NativeSampler exposes the offset function, condition states and compiled with_history operation. Evaluation uses that same operation for fresh, zero and lagged history after opening and compares an explicit zero-offset injection with ordinary stock on matched observations and noise. The frozen VLA loads once per test job. The evaluation fixture uses a deterministic actuator driver solely to exercise the simulator and causal routing on Linux CPU.
