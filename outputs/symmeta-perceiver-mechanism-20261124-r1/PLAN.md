# Which directions does the frozen tuned Perceiver use?

Registered before scoring any intervention or opening the tuned per-trace predictions. One offline question on the original UR5e π₀.₅ supports. Do the estimates follow the relative directions of issued planar commands and observed motion, or can accuracy be explained by a single cue such as command, posture or static scene? A rigid relative-direction rule would shift the prediction by a known angle for each controlled change. We distinguish angular tracking from arbitrary loss of accuracy.

## Comparisons

Use all 96 official recordings (8 tasks × 12 interface settings, three five-control chunks each), with the 64 compositional and continuous-angle OOD recordings primary. Restore the three shipped train02pro seeds 41–43 and replay every valid token with its original image pair, DIS flow, seven issued controls, three Cartesian and two jaw increments and mask. Match unrounded archived yaw, gain and sign per trace/seed, reporting the actual CPU versus training-backend residuals. Verify the tape and checkpoint digests. No fitting.

1. **Command direction at fixed camera.** For each target interface yaw increment d = +90° or −90°, transform the issued planar command to R(−d)u, with gain and gripper fixed. Then gR(y+d)R(−d)u = gR(y)u, so the correct command map changes by +d for the same physical command. Check this equality on every observed chunk and against the PR7 relabeler. First isolate issued XY alone. The native wrapper also rotates reported local Cartesian XY by −d under a full family relabel. Run that fully consistent relabel as a paired control and change local Cartesian XY alone as its complement. The command-only intervention preserves the correct action-map label but breaks the native action/sensor-frame coupling. The proprio-only intervention is a sensitivity diagnostic with the original action-map label.
2. **Camera alone.** Rotate both full square images of every chunk together by exactly ±90° (positive counterclockwise on display); recompute DIS and every CNN input. Physical movement, proprioception, command and true yaw are the same. Camera robustness predicts zero movement. A fixed camera-to-world convention as in the earlier SymMeta test predicts a shift opposite the displayed rotation; report residuals to both the signed quarter turn and zero. Strict command-only inference predicts zero.
3. **Direction with the same scene pair.** Swap before/after within each chunk, recomputing reverse DIS, retaining chunk order, mask, commands and proprioception. Cross with negating only issued planar XY (target action-map increment 180°). The simple command-versus-visual-direction prediction is an approximately 180° shift for each single flip and restoration for both. Keep camera and the unordered images fixed. Reversal is a counterfactual input, changes endpoint/appearance order, derivatives, occlusions and flow, and can conflict with unchanged proprioception. Its score uses the underlying recorded action map plus any applied command relabel; it is not a new realized episode. Evaluate both shifts and differences to the registered directional predictions.
4. **Identity.** Undo exact quarter turns at pixel level, undo the command quarter turn, and recompute preprocessing and predictions. Check input array, mask, DIS, reconstructed sensory tensor and output identity against direct upright inference. Keep a numerical preregistration and a provenance record.

## Estimands and limits

Use shortest signed circular prediction differences and absolute wrapped errors. Report paired MAE changes, mean absolute shift and angular tracking residual (mean absolute wrapped deviation from the predicted shift). For a 180° flip, raw signed shifts can cancel at the branch cut; also report signed displacements unwrapped about 180°. Average each seed's metric within a physical trace, then average physical traces within each task. Resample eight whole paired tasks with replacement, 20,000 draws, fixed seed 20261124, reporting percentile intervals conditional on these three fits. Retain all-96 and task-level summaries and every seed-level prediction. Compare relative-direction and no-shift errors on the same traces.

Accurate true relabeling is compatible with command/policy-action regularities and a public local-motion proxy. Image roll changes static orientation as well as motion. Reversal better isolates temporal order but cannot establish the learned algorithm. Distinguish evidence for using a cue from proof of an internal computation. Discuss architecture implications as design candidates only. No task rollout, architecture training or new workstream.
