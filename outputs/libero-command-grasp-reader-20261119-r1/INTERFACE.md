# Pilot interfaces

The driver calls `live.Runtime()` as a context manager, then `runtime.episode(folder, pose, wire, condition, decode, grip, decide=None)`. Folder is an unused pathlib.Path. Wire and decode signs are signed integers. `decode=None` means estimate the sign from the current ten pulse controls; otherwise apply the requested decoder to the motor/maneuver after the probe. The ten wire controls themselves are identical across assignments/arms. `grip` is 0 or 1 for a static selection. When `decide` is supplied the runtime calls `decide(commands, states)` once just before the first eligible recovery begins; its 0/1 output selects whether to execute it. Never call the callback with simulator diagnostics. State index t is the public state after t controls, with XYZ, XYZW and two jaw coordinates. Commands have width seven and are on the public wire. The callback sees the entire history up to that time including the probe. If closure threshold is never reached, record the absence of a decision. Recoveries have exactly the same semantics as the pilot, excluding the ten probe controls from closure counting. Write `tape.npz` with arrays `commands` (N × 7), `states` (N+1 × 9) and `rewards` (N). Return and atomically save `result.json` with `success` boolean, `controls`, `initial_physics`, `initial_public`, `first_motor_input` and `first_proposal` (hashes of the opening after the pulses), `probe_sign`, `choice_after` (integer completed controls at first eligible recovery, null if never), actual chosen grasp flag, native event activation, and all case arguments. Only the public tape enters the reader.

`readers.fit(samples, outdir)` runs CPU fits using samples of form `dict(commands=np_array, states=np_array, wire=+1/-1, condition="BASE"/"D17", choice_after=int_or_None)`. Save frozen weights and normalization in outdir. `readers.load(outdir)` returns a model object. `model.predict(commands, states, kind, seed)` accepts `kind` equal to "factored", "joint", or "current". It returns a two-element (X sign ±1, grasp flag 0/1) tuple. Empty support is (0,7) commands and (0,9) states; probe-only truncates to ten commands / eleven states. "current" is trained using only each fitting tape's prefix truncated at its recorded, causally detected first eligible closure; use the callback's own public prefix in evaluation. Use a deterministic analytic X decoder and separately fitted contact head for "current" (shared across seeds is fine); publish one canonical live current-only arm. For the other methods use three fitted seeds. Only fitting labels may enter training.

Evidence layout under the output attempt: `fit/pPP_wS_CASE/support/`, `fit/pPP_wS_CASE/d+1_g0/` etc. `PP` uses two decimal digits for the support pose; S is explicitly signed, case BASE or D17. `eval/` has the same structure. Static query folder names use f"d{decode:+d}_g{grip}". The driver owns stage orchestration, single-trial names, analysis, resource launcher and pinned deployment. Runtime owns gate1 library reuse and output API. Reader worker owns model fitting and feature code. Driver freezes weights and selects fixed grip before opening eval.

Every query arm must match on its pre-control reset physics and public input. Compare motor input/proposal after ten charged public pulses and record any discrepancies. These are post-action measurements. The gate's independent rollouts occasionally differed in live RGB after the same controls. The driver records such differences in the progress records and counts every measured episode.
