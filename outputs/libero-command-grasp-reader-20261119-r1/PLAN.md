# Does a previous grasp improve fresh-query success on the unseen factor combination?

The [motor pilot](../libero-command-grasp-20261119-r1/PLAN.md) opened the reader comparison. The signal for D17 can appear before the query regrasp decision, so a strong current-only baseline is essential. Preserve the frozen motor, contact maneuver, native 300-control horizon, BASE prompt and released BASE/D17 Goal 2 worlds. The private X wire convention and case persist across resets. No official test tasks are used.

## Trial design

Train on (+X, BASE), (−X, BASE), (+X, D17). Use support pose IDs 0–7 and paired query IDs 8–15, eight independent pose pairs per cell. Evaluation uses all four assignments on support poses 16–23 and query poses 36–43, with primary reporting on (−X, D17). Evaluation includes all eight pairs per cell and is run only after the weights have frozen. Gate poses 30–35 are excluded. Simulator and motor randomness use 19260000 + pose, independent of assignment. Every arm starts each episode with ten charged open-jaw wire controls, five +0.45 X then five −0.45 X, before the first motor query. Support after the pulses uses the analytic sign inferred from wrist displacement and ordinary live π0.5, with regrasp off. Keep successes and failures.

Train a factored reader and joint two-head reader using identical fitting histories, source factor supervision and three seeds 41, 42, 43. Commit the feature definitions and training recipe before any evaluation episode. Only public commands and public wrist/jaw states may enter either predictor. Normalize and pick fixed constants on the three fitting cells only. At reset use the full support or a masked or swapped support to choose both correction settings. Compare with probe-only analytic X plus the strongest fixed grip selected on fitting queries. Fit a separate contact readout for the public prefix available to a current-only arm. The current-only arm decodes X from the ten query controls and can select regrasp at the first eligible closure boundary on its own live trajectory. It also observes its query cameras through the frozen motor. Immediate public jaw behavior should make this a strong alternative.

For reset-time methods, execute every candidate live from each query start and score each reader by replaying its choice against these measured returns. These static choices start acting after the identical ten pulse controls. The current-only arm executes directly, making its choice on its own observed prefix. Compare genuine full support with cleared support, probe-only support, same-pose grasp-swapped and wire-swapped supports, joint and factored estimators, the live reactive comparator, and the supplied-factor motor. Include mask/donor controls for the factored method and report sign/contact correctness alongside successes. Report physical query controls, support length, query success and cumulative success. The matched-budget comparison gives all methods the same practice episode and query horizon; masks vary information. Also report that the standalone probe needs ten support controls and current-only needs zero prior controls.

## Decision

Only call a prior-contact advantage if genuine support beats probe-only, both single-factor donor controls as appropriate, and the current-only comparator on native fresh-query success. A tie on eight composed queries is an inconclusive or null pilot outcome. Report paired gains and losses, each fit separately and independent pose counts. Do not generalize this result to different arm morphologies. Budget at most four additional GPU-hours for the collection and evaluation panel, one distributed Pro6K, plus CPU fitting and scoring. Use separately named fresh attempts after any diagnosed failure.
