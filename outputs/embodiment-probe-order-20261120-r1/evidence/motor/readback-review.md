**Source50 recount — `large_panel_protocol.py`.** For one checkpoint and stride, enumerate the 50 unique layouts in the SHA-256-verified `dev/manifest.json`. Require one `.npz` tape and matching `.json` receipt per `(arm, layout_seed)` for Panda and Sawyer. Verify the tape hash, contract digest, arm, layout ID and seed, native `libero_goal` task 5 `BASE` reset, and pinned opening. Native steps must run from 1 through *n* (1–300), with actions matching the executed chunk prefixes. Only the final step may be done or rewarded. Count one success iff the terminal reward is 1 and the success flags equal `rewards == 1` throughout. A failure must reach step 300. Report successful layout IDs and counts per arm. Both arms must reach 38/50.

**Waypoint ownership.** Key each episode by panel hash, checkpoint hash, stride, arm and layout seed. Assign that key once across run directories and summaries. A copied receipt references the same evidence. Conflicting tape hashes for one key require reconciliation.

**Stride pairs — `stride.py`.** Pair the same frozen candidate and opening by `(body, pose)` on poses 32–35, four per arm. In `second_vs_first`, a win is failure→success, a loss is success→failure, and unchanged outcomes are ties. `wins_vs_held` uses the original stride-five tape as baseline. These pairs add no source50 episodes.
