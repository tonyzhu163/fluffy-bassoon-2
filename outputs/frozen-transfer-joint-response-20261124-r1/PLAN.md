# Can five native joint responses improve a forecast on another arm?

Registered before target replay or scoring, November 24, 2026. The decision is whether to spend a native-policy comparison on a history-conditioned decoder. Bounded current-posture IK established that many Panda grasps survive a change of controller (5/6, at least one joint saturated on 94.9% of controls). A fixed inverse solved 0/6. On Kinova3 under Cartesian OSC, a recent-error feedback controller improved its own short-horizon tracking proxy and lost four successes. Trusted encoders have also recovered imposed command rotations. None of those experiments tested this estimator on a different native joint-controlled arm. Adaptive inverse Jacobians and cross-body inverse kinematics already exist. [Panda native controller](../frozen-vla-native-controller-20261123-r1/RESULT-NATIVE.md) · [Cartesian feedback](../frozen-vla-tracking-feedback-20261123-r1/RESULT.md) · [Imposed yaw](../libero-xemb-joint-sysid-20261119-r1/RESULT.md) · [Grace et al.](https://www.eng.yale.edu/grablab/pubs/Grace_IROS2025.pdf) · [MorphIK](https://arxiv.org/abs/2609.29908)

**Hypothesis.** Public fixed-base geometry gives the direction of joint motion in task space. The elapsed response to a bounded joint setpoint can differ across bodies, postures and contacts. Five recent issued commands and encoder transitions might identify a local residual in this response. Evidence against this account would be equal or lower paired forecast error from a source-fixed or public servo model. A benefit shared by stale history would support a transferable target calibration but weaken a recency claim.

**Panel.** Use all six previously chosen Panda joint-IK tapes from the native controller study, including its failed plate start. The two ordinary BASE goals are bowl onto plate and bowl onto stove, each with released layouts 0, 2, 3 and original seeds. Selection uses only the original Panda panel. Its GPU archive contains clipped frozen π0.5 proposals and native commands, with no per-control encoder or velocity tape. Known alternate-arm motion archives used OSC_POSE. Reconstruct the settled source start and replay each archived Cartesian proposal with the same bounded current-posture IK on Panda and on a factory Kinova3 joint servo with a common gripper, scene, start TCP and gripper opening. Read actual robot joints, velocities, tool pose and native reward. Save reset differences, native configuration, commands, endpoint states, contact and saturation. Keep source failures and all measured transitions to native success or tape end. This is a replay of the source proposal sequence. No target observation generates a new proposal.

**Endpoint and inputs.** With fixed 20 Hz, normalized native action u corresponds to a goal increment δ = 0.05 u radians. The implementation multiplies a joint PD acceleration by the arm mass matrix and adds torque compensation before motor limiting. Define x = [δ, 0.05 v] in radians, y = q(t+1)−q(t) in radians. Forecast the actual next 50 ms grip-site displacement by the current public geometric Jacobian times predicted y. Primary error is world XYZ Euclidean error (mm). Also report angular error (degrees), joint RMSE (mrad) and achieved step length. Read joint position and velocity at the control boundary using the robosuite encoder sensor convention. Sample the actual tool site from the full integrated state at the same boundary, independent of the joint-only Jacobian scratch state. Keep emitted public observations for a clock audit.

**Estimators.** Compare instantaneous setpoint geometry (y = δ), hold (y = 0), public ideal critically damped PD (y = [1−(1+ωT)exp(−ωT)]δ + exp(−ωT)Tv, ω = sqrt(kp)), and Panda-fitted two-feature least squares with shared or per-joint coefficients. A velocity-only source fit diagnoses passive continuation. For each layout, exclude both matching Panda tapes when fitting or selecting the source model. Within the remaining four Panda trajectories compare public PD, pooled OLS and per-joint OLS by leave-one-trajectory-out mean TCP error; take the lowest with ties in that order as the fixed center. The history estimator fits per-joint two-coefficient ridge residuals about that center on five complete target transitions. Standardize each input feature with source RMS. Choose the ridge weight from 0.1, 1, 5, 20 by the same inner Panda validation with the fixed center type, refitted on each training fold. All source model choices and regularization use Panda only. Apply the same coefficients, regularization and current input in the stale control, changing only the five transition records supplied to the fit.

**Timing and uncertainty.** Partition each trajectory into disjoint blocks of 11 controls. In each block the first five transitions supply stale history, the next five supply recent history, and the eleventh supplies the single scored future transition. Each forecast knows the current issued native command, its starting q, v and J. No future controls enter. The shared boundary encoder is available when a preceding transition ends. Discard only the trailing incomplete block. Average paired errors within each trajectory, then equally over the three layouts and two goals. Report individual contrasts by trajectory and goal. Resample paired trajectories within each fixed goal for a conditional interval and give both goal effects to expose cross-task uncertainty. Six related trajectories and one target arm cannot estimate general task or arm uncertainty. Keep control bounds, environment contacts and native failures. Compare recent with source-fixed, public PD and stale on identical queries. Only consider a later equal-input, tuned Perceiver comparison if these contrasts show predictive headroom. This experiment estimates motion forecasts; it cannot rank decoders by native task reward.
