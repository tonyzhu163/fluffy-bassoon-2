# Source-only falsifier for a closure-time grasp offset

All five mounted grippers had the same geometry and the same close–hold–open transduction. The first native drawer replay nevertheless put the Sawyer pads 42.9 mm from Panda at the first closing proposal and the task failed within the source tape. The following inexpensive intervention tests a different explanation: a small lateral change while the jaws are still open could improve grasp placement. The held-out replay already described transfer discrepancies, so these cases are descriptive. Selection below uses only Panda and Sawyer.

Use the two existing BASE default policy tapes of libero_10/3 (layouts 1 and 4, seeds 19110301 and 19110304). On each source arm execute identity, a five-control pose hold, and matched holds offset toward either jaw. Trigger once on the first positive gripper command. During the hold, keep the jaws in their preceding open state using the previous command, and use a public TCP feedback servo to target a displacement along the observed hand's closing axis. Choose one quarter of the observed aperture, i.e. halfway from center to one finger (about 20 mm when open), independent of target outcomes. Five controls equal one policy replan interval. The target, feedback gain (one physical OSC translation scale), duration and both directions are fixed before collecting fork outcomes. Resume the original frozen tape at its deferred closing command. Count each inserted control and stop at native success/horizon or exhaustion of the recorded commands. This tests sufficiency on a fixed continuation and separates extra time from spatial movement.

Verify identical complete physics and native prefix on each arm up to the fork, actual displaced pad position relative to the matched hold, reward, contact and controls consumed. Log source results before considering evaluation on more arms. Advance a signed offset only if its source native-success count exceeds both identity and the matched hold with an unambiguous direction. A tie gives no source evidence for choosing a sign. Native success is the comparison that decides whether a signed offset is worth a fresh policy evaluation. No target labels, object poses, source solutions for a target, contact flags or future commands enter the intervention. Camera images, object/contact diagnostics and physics hashes are outside its input. The shared tape itself is a privileged diagnostic of executing the source trajectory, not a deployment-time target demonstration.
