# Can the target arm attain the same native manipulation poses?

On the original zero-shift layout 13, frozen π0.5 failed drawer-and-bowl and two-moka-pots on Kinova3 and succeeded on cream-cheese-and-bowl. The corresponding UR5e runs succeeded on all three. The native workstream owns frozen-policy rollouts and the closed-loop privileged Panda tracker. This independent test uses original LIBERO human demonstration postures, native BASE resets, forward kinematics, joint limits and collision geometry. It compares Panda and Kinova3 on Goal 3, Long 8 and Goal 6, layouts 14 and 15. Two Baige CPU cores, software rendering, zero accelerator use.

Before using a demonstration as a same-layout trajectory, check the actual released initial-state row and scene coordinates; equal indices alone are insufficient. If the recorded scene differs, transfer demonstrated approach waypoints relative to the manipulated object or fixture into the exact paired scene and label that counterfactual explicitly. Check the Panda in each comparison. Preserve actual finger positions and the physical grip-site frame, distinguish hand contact with the intended object from unintended collision, and report per-case FK residuals and constructive joint solutions. Evaluate alternate inverse-kinematics postures for the same tool goal. Treat a missing solution as an outcome of this search. Treat a solution as a geometric witness at the sampled configuration.

A repeated Kinova-specific loss of usable approach poses or arm collisions at the same goal that a different posture removes would favor configuration-aware action selection. Comparable contact-compatible pose access on both arms, particularly on the historical failure tasks, would weaken a generic loss-of-reach explanation. Native reward under paired controls would still decide whether to invest in a pose-conditioned residual or a task-space planner.
