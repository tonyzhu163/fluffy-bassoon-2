# RoboTwin scene replay qualification

On the first two clean Sidney wrist-corrected phone-stand traces, replay the original 14D physical targets through native SAPIEN `take_action` from a new seeded task. Repeat from another new task, with the same commands, instruction and observation cadence. Use action 50 as the query decision. Compare the public joint state, native phone/stand poses, articulation positions/velocities, three policy cameras and success after every command, including the decision and final target. Report bitwise equality and maximum absolute differences. Both replays must also reproduce the source terminal success and delivered count. A valid same-action, same-outcome replay is required for matched branching. With pixel or physical mismatches, limit claims to the quantities observed. These two source scenes become development fixtures. This tests reset plus prefix replay on the native phone-stand runtime. It does not test in-place PhysX snapshots.
