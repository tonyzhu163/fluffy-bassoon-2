# Does recent tool motion improve the next frozen action?

**The history signal passes the replay comparison.** At five-control boundaries, a regression fit strictly on 10 unadapted Panda/Sawyer source trajectories learned a residual persistence coefficient of 0.787. Compare predicted versus measured tool translation on long unmodified frozen-policy trajectories. The historic source motion law uses the mean current and preceding native OSC commands. The command model subtracts normal source errors explained by the current command and two preceding commands. The online model predicts the remaining error from the latest measured residual. The stale control uses the same coefficient with a three-chunk-old residual. Each test compares identical scored chunks and includes no task reward as input.

Entries are mean Euclidean displacement errors, giving each evaluation episode equal weight. The ten source episodes cover only two tasks. Source-held-arm testing applies to fitting the command bias and persistence; the original source law was pretrained on both bodies. Every held-out UR5e and Kinova3 episode favors the latest residual over stale residuals. All four UR5e episodes favor the original short-horizon law over the new predictor. The UR5e reversal and strong feedback predictability in source arms show that recent errors are not inherently evidence of a new body. The previous error and next error pointed in the same direction on 95% of scored Kinova3 chunks. On replay the pending-command norm cap would bind in 56/310 Kinova3 chunks and 17/67 UR5e chunks. Contact events were not recorded, so these interventions cannot be classified as beneficial or harmful from displacement alone. Raw replay cannot estimate response to a new issued command. **Native experiment.** Use layouts 16 and 17 of the same three BASE tasks, with four independently reset conditions on each. Untreated and static 15-support-control Jacobian baselines compare against fresh and stale feedback. Feedback uses no target support and the current target's own observed public XYZ, issued commands and source-learned persistence. Both history conditions pass through controls 1–15, start at control 16, preserve wrist and gripper, and restrict each correction to the magnitude of the pending translational command. The source inverse is regularized by measured source residual power. Compare trajectories by paired native reward, requiring exactly equal initial physical/visual states, noise and motor proposals. Fresh and stale feedback additionally share the full first 15 physical control traces. A native fresh-versus-stale difference is necessary to attribute a gain to timely feedback on this panel. With three selected tasks, it would still be exploratory evidence.

This is a task-space feedback controller with a source-fitted forward law, command bias and scalar persistence. Classical end-effector feedback is well established, and ReGround already learns deployed dynamics from motor babbling to track a frozen policy's intended movement. Our specific question is whether a source-learned single-chunk error memory can transfer without target training or a separate calibration episode. Native contact may be useful to a task even when the measured end effector misses the source prediction.
