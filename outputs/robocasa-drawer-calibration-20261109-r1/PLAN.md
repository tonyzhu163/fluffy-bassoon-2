# Can one drawer miss reveal which way to correct the next grasp?

Start with the published native Human300 SFT motor (H50/C5/K10, stock observations, original normalization); freeze it. Native OpenDrawer was 34/50 on a separate bank. This manipulation check has no trained memory, PPO, or Flora. First learned comparison after qualification: the archived KV-AD checkpoint with own support versus scene-matched opposite-sign support and reset, under the *same* motor/command protocol across those arms. Qualify the AD adapter's motor and intervention again: native JAX H50/C5 is not interchangeable with its legacy PyTorch H50/C50 motor. DPT is the next trained comparison if the paired data yield useful query-state action labels; use the same data, interface, and execution horizon for a method comparison.

Predeclared eight development pairs, with a distinct native seed for each support and query. Repeat both signs for one support and three query arms: uncorrected, inverse, and wrong (net 0, 4 or 8 cm in magnitude). A calibration sign persists across the pair. Add the net displacement **once**, on the first open-to-close command, to the physical OSC goal along robot-base +Y, before interpolation and low-level control; leave later commands untouched. This is a transient grasp-target perturbation triggered consistently across episodes, not continuous tool miscalibration. All arms preserve native termination and the same H600 cap. An episode with no closure remains in the denominator. Pin scene and noise seeds, compare initial native state, camera images, and first motor output across arms. Query scene differs from support. No student sees sign, simulator geometry, or post-offset target.

Record pre-offset public commands and measured state at every control, the native outcome, and support wrist/scene frames around first closure. Evaluator records actual target shift, signed displacement of the gripper relative to the handle at closure and 1/2/5/9 controls later, contact by both fingerpads with the target handle, and native drawer success. Report paired outcomes under both signs; eight pairs are a feasibility screen. The inverse should reduce absolute miss and improve acquisition or success against the alternatives. If the first closure is unrelated to reaching, or the controller absorbs the pulse, revise the perturbation on development before fitting. Preserving target correction in code is not evidence of a corrected grasp.

One Baige Pro6K GPU, 90-minute scheduler cap (1.5 GPU-hours maximum), 64 episodes / 38,400 controls maximum; all continuations get separate identities and usage accounting. See [parent plan](../vlrla-feedback-plan-20261109-r1/PLAN.md).
