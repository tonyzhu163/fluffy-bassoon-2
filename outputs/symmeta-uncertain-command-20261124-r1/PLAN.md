# Does uncertainty about the forward map change which bounded command to issue?

Registered before target estimates or outcomes. This is a finite-panel archived-command mechanism test. The question is whether changing the objective alone helps when a frozen motor later asks for motion in a direction weakly observed in its first 15 controls.

Bishop illustrates why a conditional mean can poorly represent a multivalued inverse using robot inverse kinematics. Here the uncertain object is the forward map. A finite distribution on empirically supported maps can retain incompatible orientations. [Bishop, 1994](https://research.aston.ac.uk/en/publications/mixture-density-networks/)

Wagenmaker, Simchowitz and Jamieson show how the downstream task determines which dynamics need to be learned. Their instance-optimal results for certainty equivalence under their assumptions make the point solve a serious comparator. Rathouský and Havlena study cautious and certainty-equivalent control with uncertain gain and describe how caution can suppress useful actuation. This study applies the familiar one-step squared-error Bayes decision to a robot interface with box constraints. It tests neither a new Bayes-risk derivation nor the value of planning future probes. [Wagenmaker et al., 2021](https://proceedings.mlr.press/v139/wagenmaker21a.html) · [Rathouský and Havlena, 2012](https://doi.org/10.1002/acs.2370)
