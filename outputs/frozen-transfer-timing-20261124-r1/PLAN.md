## Evidence informing the choice

UMI calibrates actuator-specific latencies and schedules arm and gripper commands against a shared clock. Its physical tossing ablation motivates testing whether identical commands cause a repeatable phase error here. PACE selects replan points from predicted speed valleys. Path-preserving Time Scaling sums increments to execute faster under inference latency. RoboPace limits speed during predicted contact. BID samples actions for consistency across replans. Those studies change scheduling, speed, or policy sampling. Our comparison keeps the simulation at 20 Hz and the five-control prefix fixed. It isolates a signed change in how the vertical translation command responds to a transition. [UMI](https://arxiv.org/html/2402.10329v3) · [PACE](https://arxiv.org/abs/2606.00537) · [Path-preserving Time Scaling](https://arxiv.org/abs/2611.01390) · [RoboPace](https://arxiv.org/abs/2610.09696) · [BID](https://proceedings.iclr.cc/paper_files/paper/2025/hash/0d78dd998f7b9ac79604d47a2d79bb0d-Abstract-Conference.html)

All bodies mount the same free-space sign-controlled gripper. Its half-stroke crossing agreed across arms. Lateral pad offsets and moving the placement prompt after drawer opening have already been studied. Static gain/ridge variants had mixed native effects, including identical planar/full outcomes on all 16 recent IIWA/UR5e starts. Recent-error feedback lost four of six Kinova3 pairs to raw. Those results motivate testing contact-adjacent **vertical translation** with a feedforward filter confined to two replans. ## Split and intervention

The hypothesis is that the *sign and size* of a short vertical response lag measured on a second source arm transfer to previously unseen arms immediately after grasp closure. Tool pose, contact load and workspace vary by arm and can produce errors even under equal commands. The result applies to this shared-gripper OSC benchmark and the source-derived constant lag.

- Fit only on Panda and Sawyer, replaying the same archived Panda default BASE π0.5 action tape on both. Use all four development identities libero_object/{0,7} and libero_spatial/{1,7}, starts 1 and 4, from libero-retry-headroom-20261119-r1/paired01. No query body, task, layout or reward participates. Archive inventory inspected command availability and file headers only for the new analysis.
- Evaluate without fitting or calibration on IIWA and UR5e, with all six Panda tapes from frozen-vla-native-transfer-20261123-r1/gpu01, official test identities libero_10/8 and libero_goal/{3,6}, starts 14 and 15. Each Panda reference is a measurement on the same task/start/seed and identical tape. Using these trajectories for offline scoring does not give the adapter query-time access to a source reference. Layouts repeat within tasks and across bodies.
- At the first replan **after** the first positive sign has been issued, start a ten-control window. This is the earliest full replan causally following commanded closure. The event is a command, so report actual finger contact during this window separately. Use the native 5-control blocks in both roles. If a donor has no trigger or incomplete window, list the reason and exclude that paired window from the motion fit/score. Report early termination per branch and exclude incomplete paired windows from the mechanism comparison. All actual completions count in the native fixed-tape endpoint.
- Let v be the observed world Z increment per control. Fit static g0 by least squares from Sawyer v to Panda v, and a two-coefficient law vP = g vS + b (vS[t] - vS[t-1]) separately, with no intercept, equal tape weight, including the preceding measured step at the first boundary. A first-order lead has positive b/g, a lag negative. Require full column rank, finite positive static and dynamic DC gains for interpretation. The approximation that filtering measured motion commutes with filtering action is explicitly tested in native execution. No hyperparameter search or sign selection on the targets.
- Four target branches each receive the same realized frozen Panda sequence for the full episode. Identity issues bounded u. Static issues g0*u_z during the window. Timing issues g*u_z + b*(u_z[t]-u_z[t-1]). Shifted uses the same g and circularly shifts the five derivative corrections within each currently available policy prefix by two controls. This control exactly matches pre-clipping corrections, coefficient, norm and duration per block. It remains causal because all five proposed values are available together at replan. Only Z is clipped to the legal action box. Log clipping, actual correction energy, contact and archival replay fidelity. Outside the window issue exactly the original controls. Reproduce resets, scene, untouched prefix and equal control budget. A mismatch between Panda CPU and historical GPU trajectories is reported against the observed effects.
- Primary endpoint is per-tape RMS cross-body difference in vertical *increment* (mm per control) against same-clock Panda over the window. Report also RMS vertical path error anchored to window start, native binary task completion before donor tape exhaustion, per-arm gains/losses and force-bearing finger-to-scene contact. Score native task reward only after freezing the source law. When a donor tape ends before the native horizon, record censoring. A stalled native continuation cannot be inferred from censoring.
- Compare the observed target movement to Panda under each *executed* branch. A source-only forecast on raw target responses is a separate explanatory diagnostic. Whole-task paired bootstrap intervals (20,000 draws or exact enumeration of the 3^3 ordered triplets) retain both layouts and arms and condition on the source fit. Report all task and arm effects and note the three-task limit. A temporal account loses its basis for advancement if the executed timing branch fails to improve on identity, static **and** shifted in pooled paired motion, is contradicted on one arm, or there is no separation on actual finger-contact windows. A replay reward loss without an offsetting rescue also weighs against scheduling. A narrow timing benefit without a native reward benefit on replay can at most motivate a parent-scheduled matched live test; it cannot establish policy success. No GPU request for a null or a reversal.
