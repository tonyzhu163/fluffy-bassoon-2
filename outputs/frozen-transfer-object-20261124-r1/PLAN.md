# Does a wrist camera distinguish a loaded hand from an empty closure on another arm?

Registered November 24 before collecting images or contact labels or scoring a reader. Base checkout 5d2a96b9059bc0d344e8522c77427c401cfd7e72. Exploratory, two Baige development CPU cores, software rendering, no policy inference or GPU. Parent owns Git deployment.

## Question and physical contrast

A freely carried object tends to remain nearly stationary in a hand-mounted camera while the scene moves past. When an arm approaches the wrong place, the fingers can close on air under the same command sequence. Does the *location of temporal coherence* improve recognition of actual carrying on new arm/task/layout combinations, over realized finger separation, wrist displacement, command and elapsed time? A wrist reader that ties those public sensors or works equally well on an off-center patch does not justify changing the next motor action. A reader detecting reliably across that contrast would motivate testing whether a frozen motor could use it to choose recovery. The proxy checks any carried loose object, so correct object identity is a separate question.

Xu et al. train a human-video object-flow generator and use simulated robot play to learn actions conditional on that desired motion. This study uses *realized*, past image motion from an existing motor to diagnose an interaction. RAM retrieves contact and post-contact waypoints and lifts them from image correspondences to executable 3D affordances. Neither successful retrieval nor intended flow certifies that a different arm has picked anything up. BID uses overlapping proposals and strong/weak-policy sample contrast to choose among candidate action chunks. Our archives contain the issued prefixes. They cannot compare simultaneous candidate continuations. These motivate a single cheaper observable physical comparison. ## Frozen design

- Donors are the complete raw pi0.5 commanded tapes. Use all three Panda row 15 tasks from native-transfer (goal/3, goal/6, long/8). For fitting, run each command tape on its own layout and released layouts 18 and 19. Fit one family per held task, excluding that task entirely if present in the source. All other source tape/layout combinations remain together. Seeds for own resets are the recorded seeds. For alternate layouts replace the last two-digit row number of the recorded seed with the new row.
- Target donors are all eight raw row 14 tasks for IIWA and UR5e from multiarm-confirmation and all three raw Kinova3 tasks on both rows 16 and 17 from the completed tracking-feedback archive. Run each on its own layout and on released layout 20. Pair the two branches at equal absolute control under the same entire issued prefix. The start 20 is reused across arms and both Kinova donors. Count task identities as clusters. All target arm models, layout numbers and fitted-task identities are held out of their fits. Independently report the five tasks never present in any source fit. No tuning on target data.
- Observe both branches at the original five-control cadence. Score only preterminal decisions after a chunk of five consecutive positive jaw commands. At each of the five control endpoints the evaluator independently enumerates active physical contacts. A positive has the same free-jointed object in left and right finger contact and no external support contact through all five endpoints. A negative has no external finger or gripper-palm contact through all five endpoints. Ignore fixtures, single-sided, supported, mixed or transition windows for scoring, but retain their counts. Do not condition on successful reward, time of failure, minimum jaw opening or degree of tool motion. Report opposing pairs from the same command tape/time with one physical positive and one empty. Group adjacent opposite windows with the same direction into bouts for counts. A bout counts once in sensitivity results.
- At every replan derive a baseline from elapsed control, consecutive-close length, actual aperture, aperture change, five-control XYZ displacement magnitude, absolute height change and rotation magnitude. Add common global wrist flow and single-image texture features for the spatial control and candidate. Use 96-square grayscale wrist images, fixed Farnebäck flow between consecutive public wrist observations, log median flow and mean absolute temporal brightness change. Candidate uses a fixed central square (middle half of each axis), control averages identical-sized squares at the four corners, and both use the same global features. No segmentation, target geometry, reward, contact, reset identity, future or terminal signals enter any reader. Both spatial models get the same image pair and proprioception, equal numbers of features and the same fitting recipe. Also report a command/elapsed-time comparator. Public cues remain causal.
- Standardize features on source only, weight source trajectories equally among those with labels, fit ridge logistic regression with unit inverse penalty and source sample weights normalized to mean one. No hyperparameter search. Save parameters for each fold. If a source fit has only one class, report it and use its prevalence as the fallback for every model in that fold. Keep every scored target case regardless of replay fidelity. Compare original vs replay lengths, rewards, endpoint wrist position and jaw difference where both exist. Label and score the realized CPU trajectories only.
- Primary estimate is paired Brier loss on discordant same-tape/time pairs with equal weighting within tape, followed by averaging within arm/task then across arms within task then across tasks with opposing events. Candidate minus baseline and candidate minus spatial control, lower favors candidate. Report how often the retained branch ranks above the empty branch, ties weighted half, and corresponding bout sensitivity. Report paired 95% whole-task bootstrap intervals (20,000 draws, seed 1124), per-task and per-arm counts, and secondary Brier on all eligible original-layout and crossed-layout decisions. These intervals condition on source fits, arm panel and available command draws. If there are no opposing target pairs, declare this test uninformative. If the candidate fails to improve the equal-access spatial control or the proprioceptive baseline, stop this candidate. Preserve uncertainty and contrary cases.
