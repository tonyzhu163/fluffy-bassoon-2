# Original LIBERO-PRO π₀.₅ audit and paired pilot

## Worker handoff

The primary panel locks **32 paired cases** (64 episodes). Select two tasks per suite from all ten via the SHA-256 rank of the run ID, then one of the 50 released reset indices per task by the same method. Cross each selected task and reset index with all four archived original single-factor families, `object`, `swap`, `lan`, `task`. Use the matching variant's own state file. Both arms get the filename-derived instruction from the public OpenPI registry and the same native Panda action convention. Use the absolute native agentview pose selected by the BDDL problem class. The later HF camera case belongs outside this panel. Keep Env marked unavailable. No generated cases or replacement draws.

## What the 53% includes

Zhou et al. used one officially released π₀.₅ checkpoint across four suites and specify 50 episodes per task. The source with task-level values is arXiv **v1**, Tables 2–5. The revised paper gives the design in §5.1 and results in Figure 7. The requested GitHub snapshot is `hongyuxiyohung/LIBERO-PRO@e235a970758ecd78ecbb585fca6b915a8d44d18d`. Both its README and the paper credit the authors' repository `Zxy-MLlab/LIBERO-PRO`, audited at `eafdb809426b13153aa1e4c42d6601844217dfec`. The two snapshots agree on this leaderboard. ## Task, reset and policy provenance

- **Tasks.** The manifest's `full_task_order` enumerates all 40 stems in the authors' order-index-0 registry. I compared all five suffix lists against the base list in each suite. Each has the same ten stems in the same order. The variant BDDL supplies its own objects, scene and goal even when its basename matches the original. - **Reference reset and time budget.** OpenPI seeds NumPy with 7, creates one environment per task, calls `env.seed(7)` once for that environment, then for each episode calls `env.reset()`, clears the action queue and installs `get_task_init_states(task_id)[episode_idx]` (indices 0–49). The wrapper restores the flattened state, forwards physics and refreshes observations. Ten settling controls `[0,0,0,0,0,0,-1]` precede the policy horizon. Spatial gets 220 policy controls, Object 280, Goal 300 and Long 520. The original paper confirms 50 trials per task. Its evaluation seed, reset-bank hashes, exact rows, process ordering and inference noise are unreported. Seed 7 and this reset procedure are reference-runner defaults. A JAX OpenPI server starts with key 0 by default and splits its key per inference. - **Observations and motor command.** At 20 Hz, use native Panda `OSC_POSE`, agentview and eye-in-hand RGB rendered at 256², both reversed in height and width, padded/resized to 224² and converted to uint8. Concatenate eef XYZ, three axis-angle components from the simulator XYZW quaternion, and the two gripper joint positions. The LIBERO policy returns seven channels. π₀.₅ predicts ten actions with ten default denoising steps. Execute the first five sequentially and requery. The client passes each action directly to `env.step(action.tolist())`: normalized translational deltas, rotational deltas and the native gripper scalar. Stock robosuite 1.4.1 OSC scales the six pose inputs internally (per-axis limits 0.05 m, 0.5 rad). Both arms retain this API, units, gripper sign and controller. No added action transform in the environment. The studied correction belongs only to the SymMeta policy arm. Native task success sets `done`; the wrapper computes sparse task reward. ## Paired evaluation and interpretation

1. **Freeze the draw.** The exact salt is the run directory name. Within each suite, take the two stems with the smallest SHA-256 digest of UTF-8 `run_id|task|suite|task_name`. For each, take the lowest digest of `run_id|reset|suite|task_name|i` for decimal `i` from 0 to 49, without zero padding. Include each selected stem and index in every archived family. This gives an outcome-blind, equal-weight sample for the four-family target. A shared index across factors denotes an ordinal in four different reset banks. Only the two arms **within a case** must start from identical physical state. I fetched all 64 selected files at the recorded HF commit, hashed the bytes, checked BDDL bracket counts and language, and inspected the NumPy array dimensions in each zipped pickle without executing the pickles. All 32 banks contain 50 rows. File validity and start-state equality in a live simulator are separate checks. [Case paths, hashes, shapes, prompts and 40-task frame](CASES.json)
2. **One continuous attempt per arm.** Each case gets a normal initial reset and its one released state. Clear reader memory and policy queue at that boundary. Native sends open-loop chunks from frozen `pi05_libero` through the native controller. SymMeta starts at identity and uses the frozen seed-41 passive reader, fitted before this panel. It updates using already executed motions and observations since this episode began. Preserve the reader's two identity chunks before the first correction and the same five-control query cadence. There is no detached support episode, probe motion, rewind, second attempt or state carried between tasks. Pair environment randomness and inference noise by case and query ordinal. Log both arms' start state, post-settle images, prompt, opening policy proposals, executed action prefix and the first correction. If the episode ends before a correction it remains a valid pair. The common noise bank is a pilot pairing choice. [Frozen streaming algorithm](../xemb-icml-campaign-20261121-r1/eval_stage2a_live_ur5e.py) · [Implementation handoff](CHECKS.md)
3. **Report native outcomes.** Record success for each arm, step rewards, undiscounted native return, termination or horizon, control count and any technical failure. Report both success counts out of 32, plus both-success, neither-success, SymMeta-only rescues and native-only regressions. The paired difference in percentage points is `100 × (rescues − regressions) / 32` for a complete panel. Show each of eight task blocks and four factors. Estimate sampling uncertainty at the task level within suite, retaining all four cases for a selected task together. With two tasks per suite and one state per task, any interval is exploratory. Report missing or invalid pairs explicitly, retaining their assigned IDs and giving bounds if incomplete. Native parity or a net loss weighs against extending the calibration claim to this native interface. A positive contrast supports the paired, filename-prompt four-family result. The missing Env stratum, limited task/reset draw and uncertain historical prompt prevent an estimate of improvement over the published 53%.

**Audit boundary.** This independent audit used CPU reads of Git, papers, and pinned assets at local project revision `754b162cf8a9010f4dccc6e39eebde30e0aad1e8`. It measured no policy outcomes. The historical Env banks, actual prompts, evaluation seeds, sampler state and per-episode receipts remain unidentified. The executable pilot and historical aggregate have distinct denominators and claims.
