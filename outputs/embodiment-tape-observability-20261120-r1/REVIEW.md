# What can the archived practice tape identify?

**Decision at base `1967f2b3`. Keep H1’s stop on breadth expansion.** H1 tested whether four settings per arm beat two at fixed interaction cost. Broad training reduced wrist-motion MSE by 3.75% on +45° and 4.01% on +90° with gain 0.65. Both missed the registered 10% margin and each reversed in one of three seeds. Correct and swapped support scored 0.535940 and 0.535915, versus 1.009118 for an empty embedding. Swapping donors moved the broad reader’s inferred +world-X command by a median 0.21° despite a 45° difference between ideal inverses. A common response learned from nonempty tapes could explain those scores. The empty embedding alone cannot distinguish that explanation from map identification. H1’s same-step affine fit extracted a modest donor benefit (1.01784 correct, 1.04937 swapped), but estimated eight coefficients per output from 16 transitions. Its error leaves room for a simpler dynamical model. [H1 result](../embodiment-command-frame-20261120-r1/RESULT.md) · [Fit protocol](../embodiment-command-frame-20261120-r1/FIT.md)

### Reading the offline comparison

- **What the estimator knows matters.** A predictor supplied with true query yaw and gain would measure the value of knowing the transform under a chosen response model. Predicting them from one public support tape, with labels confined to source fitting and held-out scoring, tests recoverability. If inferred factors track both settings on both arms and matching support predicts the independent query better than swapped support, the original mixed tapes contain usable setting information on this panel. H1 then left some of that signal unused. The new analysis uses planar motion while H1 scored XYZ against a source-calibrated scale. It also changes supervision, temporal features and physical assumptions. Compare donor effects on identical queries and axes before interpreting a difference in absolute MSE. Their success alone cannot assign the gap specifically to H1’s loss, its order-insensitive pooling or its optimization budget. Failure of both estimators leaves weak excitation, poor calibration and model misspecification open. [Offline plan](PLAN.md) · [H1 reader](../embodiment-command-frame-20261120-r1/fit.py)
- **Angles and amplitude can identify each other on this panel.** Both evaluation arms appeared in training. +45° is a new yaw level, and (+90°, 0.65) combines two familiar factors. At evaluation, every +45° tape has gain 1 and every +90° tape has gain 0.65. An amplitude cue could identify the setting and predict its associated angle. Report circular error and signed forward-angle separation within each arm alongside gain error and the fixed predictor. A constant 67.5° is exactly 22.5° from both settings. A pairwise gap alone can also hide a large common angular offset. H1’s 0.21° is a *change in an inferred inverse* for a single requested direction. Forward yaw, inverse azimuth and recovery on arbitrary skill directions are distinct measurements. Keep the public probe directions identical across donors, compare angles using the same sign convention, and inspect absolute errors before crediting factor recovery. [Collector and mapping](../embodiment-command-frame-20261120-r1/COLLECTION.md) · [Offline plan](PLAN.md)
- **Response timing and scale matter physically.** The source sign checks used the second step of a held two-step pulse. The evaluation probes change at every 20 Hz control. Displacement after a command can include motion from previous commands, plus settling, rotation or pose-dependent response. Align causal lags within each tape. For the one- versus four-tap comparison, hold the scored timesteps and handling of the initial history fixed. Absolute gain needs a nominal calibration in metres per command unit. A unit-direction score discards amplitude, and an estimator can trade fitted response slope against gain. Fit the slope and lag coefficients on source data only and freeze them for both donors. A shared nominal calibration can still absorb one arm’s dynamics better than the other. Correct angle with biased gain could point the motor in the right direction and still move it too far. [Pulse and mixed sequences](../embodiment-command-frame-20261120-r1/COLLECTION.md) · [Planned calibration](PLAN.md)
- **The unit of comparison is a layout pair.** A support and its paired query have different resets and probe sequences. Across settings, swap only the support donor at fixed arm, index and public support commands. Score both predictions on exactly the same query commands, steps and measured motion. Keep every evaluation layout out of slope fitting, normalization, tuning and lag selection. Show the eight paired differences per arm and setting. Arms and settings reuse those indices, adjacent timesteps share dynamics, and optimizer seeds reuse the data. This is a reanalysis of the H1 panel, so a positive result warrants fresh confirmation before a transfer claim. [Split and donor assignment](../embodiment-command-frame-20261120-r1/COLLECTION.md) · [H1 scoring](../embodiment-command-frame-20261120-r1/FIT.md)

### Go/no-go for native skill reuse

**Use the offline result to choose the next bottleneck.** If absolute yaw and gain are accurate on both settings and arms, and matching support improves paired query motion over swapped and fixed corrections, prioritize how the frozen policy uses the estimated correction. If angles separate but gain or query benefit fails, resolve calibration or the action interface first. If even true factors give little query benefit through the same predictor, the query metric or dynamics model has little power to diagnose the reader. If raw-tape estimators fail despite useful known factors, prioritize probe design before more reader training. The 16-command wrist-motion tapes contain no execution of a corrected frozen skill. [Offline decision plan](PLAN.md) · [H1 outcome](../embodiment-command-frame-20261120-r1/RESULT.md)

**Current native decision is no-go.** The best recorded frozen source motor achieved 34/50 Panda and 20/50 Sawyer against the existing 38/50 per-arm development gate. Once a source motor passes development and the registered 75/100 per-arm confirmation, the decisive next native check is whether a known inverse through the same bounded action interface rescues shifted failures on paired starts with native reward. Only if there is oracle headroom should own practice, swapped practice, a fixed correction, equal-budget analytic calibration and the raw motor be compared on fresh matched starts with the same frozen proposals at reset. Count shifted failures rescued and nominal successes broken. A learned reader tying analytic calibration would support calibration for this mapping and leave the incremental value of learning open. Familiar-arm command recovery alone supplies no evidence about new arm geometry, contact, or native skill success.
