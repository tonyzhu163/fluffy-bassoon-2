# Jaw response with a frozen motor

Baseline `757a44cd4374833cad790852df8b87ddf412e638`. CPU only. Predict jaw opening in millimetres from an issued gripper command and the two public finger positions. The observable is `1000 * (q_left - q_right)` for positions in metres. All learned parameters belong to the forward response model.

1. Use the 32 native Panda replay tapes from [the friction study](../../libero-xemb-friction-dev-20261119-r1/RESULT.md). Hold out a whole task at a time, including its default and paced tapes and both friction branches. Fit on the other seven tasks' 14 ordinary episodes. This preserves shared action tapes and starts within each test group. Give each fitting episode equal weight. No target fit or threshold selection.
2. Compare persistence, a scalar signed command gain, width-dependent sign and analog maps, separate opening and closing dead zones, previous observed velocity, and a bounded command-history state. All response models predict the next width increment by least squares. The state integrates issued signs between observed source width limits, with its step size selected on fitting episodes. It starts from the first public width. Compare one-control predictions and recursive five-control endpoints, where only the starting width, prior displacement and command sequence are available. Break out single-step errors at sign reversals. Average errors over episodes within task, then over tasks. Bootstrap paired task differences.
3. Freeze the model from the Goal 1 holdout fold and score independent BASE reversal probes on three arms at one common Goal 1 layout. All share a PandaGripper. Also score the remaining four five-control blocks in each [paired frozen π₀ and π₀.₅ prefix](../../xemb-pi0-source-smoke-20261122-r1/RESULT.md) after one observed block. Use the previous block's mean velocity where only endpoints are saved. Check whether two opposite five-control support pulses recover direction on a separate inverted-wire cohort's third pulse. Archived sign predictions provide context only.
4. Vary positive and negative input magnitude at matched histories on an isolated, pinned MuJoCo PandaGripper. An amplitude effect on this component would contradict amplitude-invariant sign actuation. If the history model fails to improve on the velocity control on held-out blocks and reversals, prefer the simpler velocity model for this readout. Persistence provides the stationary-jaw baseline. A history advantage shows predictive state dependence. Mechanical backlash would require distinguishing it from actuator integration, damping and contact.

The endpoints are response-prediction errors and component motion. Native task reward under these predictions requires a separate motor retry.
