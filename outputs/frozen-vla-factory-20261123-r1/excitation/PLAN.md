# Equal-budget excitation of a frozen motor's planar interface

Baseline `757a44cd4374833cad790852df8b87ddf412e638`. On the locked UR5e panel the earlier wider-family experiment found poorly conditioned passive supports and unstable full-map estimates. Does changing the directions of three five-control bursts make a general 2×2 map recoverable? The explanation would lose support if two directions improved conditioning but failed to reduce paired map error against both one direction and passive, especially when the passive template had little spread.

1. Score the 96 recorded UR5e passive supports for each frozen motor (π₀.₅ world-FK export and π₀ qualified crossarm export). Report their original yaw/gain map errors. Use the four nominal Panda pulse NPZs on Goal 5 and 7 for source calibration. They supply the shared command-to-displacement scale, one-chunk carryover and residual noise scale. Their tasks and robot differ from the eight UR5e test tasks. Keep the target yaw, gain and condition name out of the estimator.
2. Reconstruct UR5e in the eight released BASE task scenes, layout 11, in headless CPU MuJoCo. For each task and motor, rank the twelve passive traces by singular-value ratio of their three **unit** XY directions. Use ranks 3 and 10 for low/high angular diversity. These templates are open-loop constructions from frozen-policy commands. For each template execute (a) the first direction repeated, (b) the three passive directions in order, and (c) the first direction, its +90° perpendicular, and the first direction. Use the same 0.155 or 0.62 command norm for every burst in a comparison. The high level equals the existing nominal Panda pulse, the low level is one quarter. Every arm gets 15 controls at 20 Hz. Use zero Z and angular commands with jaw held open. Start each run from an exact fork of the same settled task state.
3. Draw orientations per task from a fixed RNG, independently of templates and archived labels. Compare positive- and negative-determinant maps with singular values 1.45 and 0.70, keeping the singular axes paired. No mapped command can clip even at the higher norm. Read three XY displacements from trusted world-frame kinematics. Apply identical endpoint jitter across designs within a matched comparison. Also score clean measurements. These are new simulated measurements with constructed commands and maps. The separate recorded supports preserve their original VLA feedback and sensor history.
4. Estimate a scaled rotation and a general ridge-regularized 2×2 map anchored to that rotation. Fix the ridge at the source residual variance, in squared displacement units for a unit-size map correction. Include nominal identity and unregularized minimum-norm controls. Primary endpoint is relative forward Frobenius error over both axes (equivalently RMS error on the two basis vectors normalized by the true map norm). Also report the repository's residual operator error after pseudoinverse correction, including its tails. Hidden matrices enter the simulation wrapper and scoring only. Readers receive commands, three displacements and common source calibration. They have no condition key or query feedback.
5. Average paired errors within task, bootstrap the eight whole tasks jointly across motors, map signs, amplitudes and templates. Split results by sign, strength, passive spread and motor. This screen measures identification using known kinematics. Task returns after correction require a separate closed-loop query. CPU only, 0 GPUh.
