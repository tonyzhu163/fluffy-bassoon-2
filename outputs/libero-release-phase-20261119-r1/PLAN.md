# Can the stage of a jaw opening tell a robot how to interpret a zero reward?

Train three completion regressors on the same 30 nominal, early-open and descent-open practices at Goal 4 BASE poses 10–14. The first uses the six public completion summaries. The second adds the time of the largest ten-control jaw widening during continuous commanded closure and time since closure began. The third adds wrist height relative to the closure start, descent from the highest wrist position since closure started, and signed wrist travel in the preceding ten controls. Align wrist features to the beginning of the widening window. No model receives simulator grasp, object pose, event stage, destination identity, query pose or future query state. Use the same feature scales, ridge penalty 0.01, bounded completion estimates and reward likelihood rule for all three. Save the three fitted models before running new interrupted practices.

Simulate normal, early and late openings for both destinations at practice poses 15–19, then score the same frozen readers on the measured nominal query options at poses 24–27. The practice poses previously supplied nominal query outcomes, but the interventions at these starts have not been run in this study. No fit uses their data. Every cyclic pair of practice poses is crossed with all four disjoint query poses to remove dependence between a support pair and the available query. Use the default-support bank's nominal motions for both archived query goals. Reproduce each sham and pre-event prefix from recorded controls, freeze the query choices before query replay and retain untriggered cases. All three comparisons use the same 30 practices and eight query episodes.

Primary comparison is the phase-aware reader versus clock plus public summaries on early-versus-late supports, with native success across all assignments. Report squared error per physical practice, goal identification, motor ceiling, the both-triggers subset and paired changes versus the same-start reassigned-motion baseline. Use normal/early and normal/late for interpretation. Also report the older bowl-trained joint completion model on this panel. If event-aligned wrist features improve completion prediction without improving native query success, the evidence is confined to the prediction task. CPU simulator replay only; official test identities excluded.
