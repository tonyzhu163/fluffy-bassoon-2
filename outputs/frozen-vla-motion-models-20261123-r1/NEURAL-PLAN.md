# Can a source-trained nonlinear feature map improve the body correction?

The linear Jacobian results above motivate a capacity check before spending GPU time on larger bodies. Keep the same support/query splits, shared source prior, regularized target update, native interface and scores. Fit one four-unit tanh residual network over current and previous normalized commands on source-only error. Give its hidden activations to a target ridge head alongside the three current-command coordinates. Remove the source linear span from those features and equalize their total source power with the 3D current-command basis. Zero episodic residual weights recover the pooled source motion law. A tied comparison keeps the learned pooled law and permits only the original three coefficients to change at calibration. This separates learning common nonlinear dynamics from learning robot-specific nonlinear dynamics.

Fix the target penalty at the linear experiment's source-selected value, width at four, and optimizer initialization seeds at 41, 42 and 43. Fit each source arm in turn and predict the other, then pool both source arms and evaluate the three held-out arms. The principal statistic compares the seed-averaged nonlinear model to the same ordered task pairs from the linear run. A non-improvement on source transfer and new target arms, or gain attributable entirely to the shared source law, undermines the case for a nonlinear target adapter. Report source and target effects, each seed's effect, and the effective rank of the three calibration commands. This is exploratory conditional on the earlier linear results, and uses the same 24 target traces. No task reward enters any training.
