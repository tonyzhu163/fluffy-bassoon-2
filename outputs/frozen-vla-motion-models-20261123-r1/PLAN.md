# Does a native arm need a learned motion correction?

Frozen π0.5 supplies every action proposal. A black-box local forward model learns the relationship of current and previous translation commands to measured end-effector displacement on nominal Panda and Sawyer. A single target support episode (three five-control chunks on start 11) updates the current command Jacobian around that source prior. The other coefficients stay fixed. This probes differences in arm/controller dynamics when all robots share the native Cartesian command convention. It assumes trusted metric end-effector positions during calibration.

Use only nominal Panda/Sawyer training cases from the original archive and native, untransformed UR5e, IIWA and Kinova3 cases from the official test tasks. Select regularization by leave-one-source-arm-out prediction on different tasks within that pseudo-target. Compare the unadapted source law, a target-fitted planar similarity residual, a target-only ridge and the source-shrunk 3D Jacobian. A wrong-arm same-task support control tests whether any gain specifically needs the target arm. Predict each additional target task using each distinct target task for support. The endpoint is mean Euclidean command-to-displacement error in mm per five-control chunk. Report task jackknife uncertainty, excluding a deleted task in both roles.

Indistinguishable or worse errors for the 3D residual against the planar or unadapted model undermine the architectural hypothesis. Equal wrong-arm performance weakens the arm-specific interpretation. These short, early trajectories cannot establish closed-loop task success. Export the prespecified 3D model's nominal correction on each task to a separately owned native-reward evaluation. That runner can compare unadapted actions, the planar model and the 3D model from identical launches. A frozen policy already near its task ceiling limits the detectability of benefit. This workstream uses Baige CPU only.
