# Does a calibrated support reader improve native task completion?

Registered 2026-11-24 before receiving new reader predictions, fitting outcomes or retry rewards. Starting checkout ffbfc06cf5314595371c4d24b0ab26daf4bfb5c0. The parent owns the Git pin and release. The attached case table uses only historical support identities and the following prospective assignment.

## Problem and hypothesis

A frozen Perceiver can infer a control frame from camera motion and locally reported motion. Its yaw shifted substantially when only the image was rotated. In prior unperturbed UR5e π₀.₅ retries, the tuned reader had lower offline yaw error yet finished 141/192 OOD retries against SymMeta's 153/192. That comparison changed all three correction factors. We ask whether supplying an explicit camera-to-reference transformation before reading the support buys native successes beyond a Perceiver trained with the same public calibration and source camera variation. The alternative is that both learn sufficient compensation, or that residual yaw errors have little influence on retries. ## Outcomes and update

Primary is the physical study's task-weighted percentage-point difference in native binary success, A minus B. Report successes/attempts for every arm, both discordant counts, per-task paired differences and 95% whole-task paired bootstrap intervals. For eight physical supports on two tasks report the two task effects and range; any two-task interval is purely descriptive. Report the digital study separately with its own denominator. Report wrapped yaw errors per case from the retained post-angle table and the covariance of A/B successes and of task-mean yaw-error reduction (B−A) with task-mean success gain (A−B). These associations are descriptive. Tabulate camera signs and both OOD regimes. No per-case improvement filter, pooling across studies, or independent-episode uncertainty. Native success, reward trace, return, termination and truncation must reconcile under the actual worker.

A positive paired physical effect supports using calibrated yaw for these starts conditional on the shared gain/sign. A null or reversed effect despite improved physical yaw weakens the claim that this correction improves completion. An imprecise result leaves the benefit unresolved. If the parent declines after paired offline physics, the evidence concerns yaw only. Native wins might still arise from the task-specific cost of errors, and native losses could arise despite improved mean yaw. Neither counterfactual establishes general moved-camera policy competence, independent command/sensor remapping, or transfer to unseen tasks.
