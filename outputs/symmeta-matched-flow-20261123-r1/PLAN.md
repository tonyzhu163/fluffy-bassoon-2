# Does the learned visual motion reader add value under equal source supervision?

Use the original 1,344 labeled Panda and Sawyer passive traces to fit a linear projection from pooled DIS flow and measured vertical displacement to planar motion. Compare it with the frozen seed-41 visual reader. Keep both estimators blind to issued horizontal commands until geometric alignment. The source fit may use issued commands and the trace transform labels for supervision. Record the precise targets, flow pooling and source membership. Use no target fitting, target-derived hyperparameters, target camera calibration or world-position labels. Freeze the implementation before computing target errors.

Use the same three five-control chunks, normalized direction alignment, equal chunk weights and the same estimated gain and gripper sign for both arms. For UR5e × π₀.₅ the primary offline outcome is the paired difference in mean absolute yaw error on 64 held-out task–transform pairs. Also report all 96 pairs, per-task effects and uncertainty resampling eight tasks. Retain estimates, tape identities, fit and source revision. If the linear readout matches the learned one, the earlier gap to a nominal-source brightness estimator gives little evidence for the learned architecture itself.

Test the operational consequence on the same 96 second-attempt queries with native rewards, identical resets and policy noise. Both arms use the common solver, including the learned arm, so run both afresh. Report paired wins, losses and ties, task-cluster uncertainty and the held-out subset. A yaw advantage with little or uncertain native-success change supports an estimation claim only. Use Baige CPU for the offline fit and one distributed Pro6K job for the paired evaluation, initially up to four GPU-hours. Scope the paper's claims to the tested protocol. No superiority claim about a named published method rests on a local proxy.
