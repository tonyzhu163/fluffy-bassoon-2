# Source-only pilot review

**Hold the full launch until the parent qualifies the complete snapshot and the first native source pair.** The upstream Transformers 4.53.2 API supports the motor’s forward path. The earlier runtime receipt covers a CPU SigLIP vision tower. It does not establish that the full motor loads, trains, reloads and issues a native action on the deployed GPU. This review used source and existing receipts only.

| Priority | Evidence and consequence | Correction for the parent |
| --- | --- | --- |
| High · weight staging | `run.sh` lines 43–44 hard-code MIX and check only the index. Lines 100–102 collect both 16-pose banks before the trainer verifies the tokenizer and all three shards. An index-only snapshot wastes collection time, and a complete custom-path MIX or the documented PT fallback cannot be selected. The earlier [weight receipt](../libero-witness-encoders-20261119-r1/pt-weights.json) identifies 437 extracted vision tensors. | Honor the weight-path override and run the existing verifier before collection. In the allocated runtime, qualify one actual update, selected-checkpoint reload and native proposal from a small source bank before committing to 300 updates. Keep the official digest allowlist. |
| High · source collection | [DEMOS.md](DEMOS.md) defines first qualification as four accepted tapes on poses 0 and 1. The production launcher begins with 32 body/pose requests. A setup error breaks only the route loop for that pose, and the launcher inspects errors after the bank returns. An invalid setup can repeat across the entire bank. | Require the documented small qualification or its existing receipt before scaling. Propagate an infrastructure exception immediately after writing its failure receipt. Preserve ordinary native misses in the denominator. |
| High · stage pose contracts | The launcher's default poses are disjoint. The standalone trainer accepts arbitrary pose filenames and numbers in `motor_data.py` lines 17–19 and 53–65. Qualification checks only 0–29 after SFT. Reader fitting accepts any pose below 30 except 20–23, with no intersection check against the qualified motor's training and validation poses. A direct invocation can reuse motor selection poses as purported fresh adapter demonstrations. | Enforce motor poses 0–15 before loading frames or updating weights, and joint poses 24–27 before collecting practices. Verify the joint tape's body, pose and seed against its accepted native collector receipt, as the motor does. |
| Medium · native startup | `run.sh` lines 66–78 retain the established GLVND setup and strip conflicting Torch library paths. `sim.py` lines 133–140 turn missing GL strings into empty strings. The previous [native runner](../libero-crossarm-20261120-r1/runner_native.py) required an NVIDIA vendor and nonempty renderer after reset. Qualification discards both strings. A CUDA probe alone cannot identify the renderer that produced the pixels. | Restore the NVIDIA check for distributed jobs, retain the explicit Mesa CPU qualification path, and save actual vendor and renderer in native reports. |
| Medium · reader evaluation cost | Each practice or query starts a new simulator interpreter. Each control sends two full 256 × 256 RGB frames across the pipe, including the four intermediate observations discarded during a five-action prefix and every practice step. Across ten full-length target queries that is about 1.1 GiB of image payload alone. | Reuse the established simulator process across fresh resets. Return measured motion and termination per control, with frames only where the motor replans. The [previous chunk transport](../libero-crossarm-20261120-r1/runner_native.py) already implements terminal-aware stepping. |

**Backbone and information flow.** The tagged implementation exposes `full.model.language_model.layers`, aliases `image_token_id` to `image_token_index`, converts legacy checkpoint keys, scatters image features into the ordered placeholders and returns `last_hidden_state`. Under SDPA the label-free prefix attends bidirectionally. The motor uses 512 image placeholders for two 256-patch views. The prior [runtime receipt](../libero-witness-encoders-20261119-r1/vlm.json) records the package version but only exercises vision.
