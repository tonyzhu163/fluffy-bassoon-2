# Mapreader → native release, version 1

Give the parent an immutable JSON file and its SHA-256 after the source selection and prediction export are frozen. The release contains no offline target scores. A file reference below is an object with absolute Baige shared `path` and lowercase `sha256` of its bytes. Use full-precision forward 2×2 matrices in row-major order (world = A @ issued column). Emit from the actual inference/fit call, never transcribe numbers.

- Top-level fields are `version` (1), `reader_pin` (full commit), `source_freeze`, `checkpoint41`, `source_law`, `source_qualification` (file references), `qualified` (boolean), and `rows`. A qualification receipt may document a failure. Include the source-only config, checkpoint SHA, split/selection and achieved held-source control results in or through the referenced source records.
- One row per `arm,suite,task,family,schedule,seed`. Native consumes UR5e/IIWA, 8/6/8/8 in mapreader suite order, general+/general-, passive/along+/along-/orth+/orth-, seed 41 (80 rows). Additional families/seeds may be included. Use integer task and seed. Seed identifies the direct model. The physical solver is the fixed incumbent.
- Each row includes `case` (fixture case.json), `source_archive` (original layout-11 proposal tape in case.source_record), `support_tape` (actual layout-17 <family>-<schedule>.npz), `source_law_sha256`, `checkpoint_sha256`, `structured` and `direct` (fitted forward matrices). The true map/seed come from case.maps[family]; never use the oracle as an estimate.
- Include `input_sha256` on each row. Compute lowercase SHA-256 over concatenated C-contiguous little-endian float64 bytes of support_tape['issued'] (15×7) then support_tape['fk'] (16×3), in that order. This identifies the common permitted physical inputs before deterministic feature construction. Keep the separate hash of the entire NPZ, including audit-only fields. Confirm in the source receipt or accompanying export code that both estimators see only issued controls, encoder FK/derived displacements and fixed source features. Physical env inputs, goals, family, truth and future queries must stay outside their inference functions.
- Include `inverse_fixture` as an array of objects with `A` (2×2), `q` (N×2 bounded nominal commands), and `issued` (N×2), generated with the actual mapreader evaluation correction function. At minimum cover an invertible nonsymmetric reflecting map with saturation and a rank-one map. This is a source-independent convention test. Export code or separately named file refs to source-selection and estimation code may accompany the release. If names differ, document the deterministic field mapping before native preparation.
