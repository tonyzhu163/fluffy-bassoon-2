# Does the adapted frozen motor solve more tasks?

## Problem

A 15-control lateral calibration improved forecasts on bounded maps. A successful forecast does not give a task outcome. This study measures whether the same frozen π₀.₅ solves more released simulation tasks with a structured map fit or with a tuned Perceiver reading identical physical support. The separate camera study does not enter this experiment.

## Hypotheses

1. The lateral structured reader improves native success over the source-selected direct reader on the same tape. A negative paired difference counts against this; an interval spanning zero leaves the direction unresolved. A source-unqualified direct model cannot settle the architecture question.
2. Information from a lateral pulse improves native success relative to passive and effort-matched along-line calibration for each reader. A flat or negative within-reader difference weakens the proposed transfer of forecast gains to task completion.
3. Correcting the injected interface matters for this motor. Compare both lateral readers to untreated raw and to the true-map clipped inverse. Report the paired true minus raw and true minus each fitted reader gaps. The privileged known matrix corrects an interface under command bounds; it is not a mathematical success ceiling. Task policy limitations and clipping can persist with a known map.

## Prior

On the earlier independent tasks, the same source-law solver gave 12.08/11.71/8.00 mm physical forecast error for passive/along/lateral on swap/general draws. That evidence favors lateral excitation for estimation but gives no direct native reward prediction. Prior native comparisons of other readers showed gains, ties and losses across arms. Bounded feasible commands, body dynamics, feedback and an imperfect frozen motor can all break a monotonic relation between forecast error and task reward. No quantitative native effect size is assumed.
