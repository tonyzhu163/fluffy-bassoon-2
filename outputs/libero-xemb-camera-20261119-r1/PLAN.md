# Physical agentview camera roll at frame zero

Can a reader identify an actual roll of the fixed external camera from one public reset image on a task it did not see during fitting? A reader that correctly identifies all three angles on all eight development tasks falsifies frame-zero blindness for this panel. An imperfect score measures this reader's errors and cannot establish blindness. Stop after this audit. The separate action and local-proprio yaw experiment changes a different quantity.

Use the pinned LIBERO-Pro2.0 BASE simulator on Baige Linux CPU with Mesa software rendering, zero GPU-hours and no motor. Use SPLITS.json's registered eight-task fitting subset and the eight development tasks. Assert split membership and disjointness. Use one released settled reset per task, initial state 0 in fitting and 13 in development. Seed each reset with 19111900 plus its index in the sorted fitting-then-development list. Use no test episodes or outcomes.

At native public frame zero record nominal, +90° and −90° roll at 128 × 128, then return to nominal to check reversibility. Positive roll is right-handed about the camera's forward optical axis (MuJoCo camera-local −Z). Right-compose the fixed camera's model quaternion and call mj_camlight to update only derived camera/light geometry. Read cam_xmat and cam_xpos relative to the robot model's root body. Require the measured relative rotation to equal the signed target, with fixed center and optical axis (absolute tolerance 1e−10 for doubles). Compare complete MuJoCo integration state, all body positions and orientations, every public proprio field and the wrist image against the original reset by byte equality after each exposure. Require nominal RGB to reproduce the released frame, both rolls to change pixels, and restored nominal to reproduce it again. Stop and record failure if any validity control fails. No actions follow reset.

Before development, fit a separate arithmetic mean 16 × 16 RGB template for each angle from eight fitting images/class. Use nonoverlapping 8 × 8 block means of the native public pixels and select minimum mean squared error, with ties in nominal, +90, −90 order. The reader receives only a single image. Freeze and save the templates before the first development reset. Report the confusion matrix, per-angle and all-three-per-task scores, circular error and smallest runner-up margin. A cleared-image control supplies the same task's nominal frame for every orientation, for a balanced 1/3 reference. Save native evidence and exact source. Limit inference to these three angles and one reset per task.
