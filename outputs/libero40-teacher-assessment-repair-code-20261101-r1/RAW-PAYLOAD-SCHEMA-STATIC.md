# Source7ef raw capture schema and storage bound scope

This is a static reading of the immutable source7ef capture/rollout/server code, not a new data scan or payload deserialization. It does not certify a1MiB raw-file maximum.

For each completed steering decision, `CaptureMotor.infer` writes one `*-inference.pkl.gz` before the physical RPC; `CaptureSimulator.step` writes one `*-outcome.pkl.gz` after a returned RPC. A failed RPC can leave only the inference. Each returned reset writes one `*-reset.pkl.gz`. The assessment's `FrozenTeacher(output=None)` emits no separate actor-proposal files, and its embedded qualification calls the uncaptured underlying motor. Therefore the owner's2592 completed chunks and162 returned resets imply exactly `2*2592+162 = 5346` raw files for this stopped run, assuming the producer's completed-chunk count and no extra incomplete inference. Failed161 is separately proven to contain exactly one reset and zero inference/outcome. This formula is not an independent replay of all old journals.

Each public observation has two256×256×3 uint8 cameras (393,216 array bytes) and8float32 proprio values (32bytes). Inference adds10×32float32 noise (1,280bytes),10×7float32 decoded actions (280bytes), instruction and metadata; these actual pixel-SAC assessment roles do not ask CaptureMotor to populate its pending public-feature field. An outcome adds at most10 requested and10 executed seven-dimensional float32 actions (at most280bytes each), at most10 raw rewards, booleans/counters, one next observation and the inference path. Reset adds its seed/state IDs, nominal/composite/camera hashes and the actual simulator-state array. The saved-array diagnosis proves92float64 values (736bytes) for s05; source7ef does not impose that length globally across40 environments.

`raw_record` pickles arbitrary supplied objects and gzip-compresses them without an encoded-size limit. Instruction/path lengths, generic serializer metadata and actual simulator-state size are not globally bounded to1MiB by these functions. Accordingly1MiB is a generous engineering estimate for the described payloads, not a code-enforced historical maximum. Do not retrospectively turn that estimate into a certified storage cap. The owner may establish a conservative old-output upper bound by direct stat of its known file classes/paths and explicitly bound unknown classes; no recursive old-forest rewalk is requested. Unknown/unbounded classes keep GPU admission held.

The repaired child additionally saves two small reset evidence payloads per started role: `reset-input-features.pkl.gz` and `reset-identity-audit.pkl.gz`. They retain actual reset data, computed4104 feature vectors and comparison evidence without changing pixels. These are extra evidence files, not extra physical episodes, and must enter the new-child storage allowance. Future raw decisions still produce exactly two raw-RPC files each. Trace/RNG/receipt/case-reference/clock/server/proof files are separate classes and cannot be counted as raw files or omitted from the32GiB aggregate bound.
