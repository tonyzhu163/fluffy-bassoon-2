## What the code and saved runs establish

| Path | Exact behavior |
| --- | --- |
| PaliGemma R1 | Let `p` be one bounded seven-channel motor proposal. The head reshapes `Wz+b` into eight rows, a matrix `A` and an offset `c`. `adapt(z,p)` returns **unclipped** `p + pA + c`, including the gripper. The learned inference wrapper clips every coordinate to [−1,1]. Empty practice supplies a literal 16-vector of zeros, so all eight rows come from the learned bias `b`. At joint update 0 both head weights and bias are zero, giving the raw bounded proposal for every history. After fitting, even zero context can change it. Saturation can also hide a nonzero residual on an individual coordinate. ## Two falsifiable decisions

1. **Can a closed gate reproduce raw after fitting?** Branch at final issuance. If forced closed, practice is absent, or the learned gate abstains, issue `raw.copy()` directly. When open, use the existing bounded correction. Test the fitted model with nonempty practice and forced closure on cached interior, boundary and gripper commands. Require identical shape, dtype and bytes on **every** issued prefix through termination against raw on paired deterministic resets. Any mismatch stops the identity claim. This tests implementation. Evidence of learned restraint requires the gate to choose closure itself on valid, nonempty practice.

2. **Can public practice spare nominal successes while retaining shifted rescues?** After source qualification, use stock Panda/Sawyer as nominal and prespecified changed dynamics on those source bodies as shifted. For each independent support/query pair, fork raw and always-correct from the same query reset and motor noise. Each follows its own observations to native termination. Label gain, tie or loss by `Y_correct − Y_raw`. Retain both types of tie. Include ordinary successful raw episodes and correction failures. If source development produces no rescues or no losses, stop before fitting a selector.

   Cross-fit by source layout and practice lineage, keeping all repeats, arms and forks of a lineage together. Each label comes from a correction trained without that fold. Fit a small three-class gate on public command–motion summaries and the first raw chunk. Decide once per episode. Arm ID, shift flag, filenames, query rewards and future frames stay outside the gate. Fit the final correction on source training only. Calibrate gate probabilities on fresh source pairs from that **final** correction, using a single fitted temperature. Freeze both checkpoints and calibration before independent confirmation. Report held-out multiclass Brier score versus constant training prevalences and predicted versus observed gain/loss by score band. Compare a first-chunk-only gate and command-matched practice swapped at the gate input alone. Hold both executed branches fixed to isolate selection.

**Cheapest decisive comparison.** Reuse complete, matched source raw/always-correct tapes with the same policy hashes and opening. For an episode-level gate, its outcome is exactly the selected branch’s native outcome. Score raw, always-correct and gate from two rollouts per case. The historical target pilots supply context only. Precommit to opening when calibrated `P(gain) > 2 × P(loss)`, with ties closed. The two-to-one harm cost and thresholds below are proposed design choices. No selective-gate performance has been measured.

| Confirmation endpoint | Proposed pass rule |
| --- | --- |
| Nominal harm, separately per source arm | Count raw-success/gate-failure over **all** paired layouts. Require its one-sided 95% exact upper bound ≤5%. Also report losses per raw success and the fraction of nonempty histories closed. With zero losses, 59 independent layouts per arm are the minimum for the 5% bound. |
| Benefit on shifted dynamics | For each source arm report gated versus raw and versus always-correct gains, losses, both-success, both-failure and paired difference. Require a positive 95% lower bound for gated minus raw in each prespecified shifted arm. Require at least one always-correct loss averted to support a selective advantage. |
| Unnecessary abstention | Among shifted cases where always-correct succeeds and raw fails, count the fraction closed. Require its one-sided 95% exact upper bound ≤50% on each arm. A zero opportunity denominator leaves this unresolved. |

Use one independent layout–support pair per arm per unit for exact intervals, and R2’s simultaneous gain/loss bounds for each paired difference. If histories or layouts repeat, group at their shared lineage and use cluster-level uncertainty. Report missing cases and worst-case bounds. Advance only if all endpoints pass, pairing is intact and the shifted paired lower bound exceeds zero versus each gate control before attributing gains to practice. Insufficient precision leaves the gate unqualified. [Paired estimator](../libero-paligemma-dualarm-20261120-r2/large_transfer_stats.py#L64-L91)
