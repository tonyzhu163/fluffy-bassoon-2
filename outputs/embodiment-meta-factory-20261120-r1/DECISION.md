# What to establish before scaling the embodiment learner

Start with a source-only test that can distinguish three possibilities. A correction may be impossible for this motor, one correction may work for every setting, or different settings may genuinely need different corrections. Only the third result warrants training a reader to select a correction from history.

## What the existing numbers measure

The motor starts from general PaliGemma‑3B‑Mix‑224 and learns source actions from simulated Panda and Sawyer demonstrations of one LIBERO-Pro2.0 Goal 5 plate push. On the same 50 distinct new object layouts per arm, the original frozen motor scored 25/50 Panda and 6/50 Sawyer. The extended regression motor scored 34/50 and 20/50. An equally long categorical-action fit on the same expanded bank scored 14/50 and 15/50. The training bank and optimizer budget changed between those two checkpoints. Within each checkpoint comparison, both arms used exactly the same frozen weights, inputs, action cadence and native success predicate. These are raw source results. UR5e has appeared in earlier pilots and is excluded from training and model selection in the current study. [Source counts and hashes](../libero-paligemma-dualarm-20261120-r2/evidence/source50/native.json)

The earlier reader trained on two source arms, two support and two query trajectories per arm, sixteen transitions per trajectory. That gives eight training trajectories and 128 transitions, plus two held-out trajectories. The subsequent R2 joint-fit recipe takes 16 sampled action targets per arm for 150 updates while reusing four source support trajectories. The earlier completed fallback used motion-matching targets. The model pools action and measured motion into a 16-dimensional context. The context selects an affine residual on each frozen seven-dimensional action. The present reader receives no images. A useful predictive context can emerge without ever assigning a robot name. [Meta-training audit](SCALE.md) · [Reader source](../libero-paligemma-crossarm-20261120-r1/adapt_eval.py)

## What the no-op already does

In the previous adapter, clearing history sets the context to zero but still applies a learned bias. In one archived example it changed the raw gripper command from 1.000000 to 0.992186. The factory tested a separate explicit off switch against all 100 archived native episodes of the 6,400-update regression motor. It returned the original bytes for **19,563/19,563** issued controls (8,066 Panda, 11,497 Sawyer), with zero residual calls. This verifies a selectable identity path on recorded proposals. A learner choosing that path correctly in a fresh closed-loop episode is a separate, open hypothesis. [Native readback](identity-native.json) · [Gate audit](IDENTITY.md)

## Ranked decision tests

| Priority | Hypothesis | Cheapest comparison and decision |
| --- | --- | --- |
| 1 | The frozen motor admits a useful, setting-dependent correction. | On identical native starts, compare raw, one common correction, an analytic calibration, and a privileged setting-aware correction through the same bounded action interface. Include a nominal setting and two settings that require opposing corrections. Count failures rescued and successes broken. If the oracle cannot improve, revisit the motor or allowed action correction. If one common correction suffices, use it for that setting. [Motor](MOTOR.md) |
| 2 | Public history identifies the control-relevant property. | Cross hidden settings within the same arm. Match probe commands and practice layout, and evaluate on a separate query layout. Compare genuine history, command-matched swapped history, frame zero, and analytic system identification. Predict an unseen action response and check native success. For a contact property compare pre-contact and post-contact windows. Improved robot-name accuracy alone leaves this hypothesis open. [Information](INFORMATION.md) |
| 3 | The learner can abstain selectively. | Provide an explicit hard bypass that executes the raw action. Verify byte-for-byte equality when closed. On independent nominal and shifted pairs compare raw, always-correct and learned-gated correction. Count raw successes broken, raw failures rescued, gate-open rate, and false abstentions on correctable cases. Use nonempty practice on already-working cases. A gate that always stays closed fails the shifted-gain test. [Identity](IDENTITY.md) |
| 4 | Additional independent dynamics settings improve extrapolation at a fixed interaction budget. | Compare two source arms × two settings with two arms × four settings, each using 96 independent sixteen-step tapes and the same optimizer budget. Assign disjoint support and query layouts, block held-out parameter values and compositions before fitting, and use paired training seeds. Then add source robot families and run leave-one-family-out validation. The first comparison changes interface diversity on two kinematic families. [Scale](SCALE.md) |
| 5 | The improvement survives transfer with the motor held fixed. | Freeze one checkpoint, adapter, gate threshold and study settings. On paired new starts compare raw, correct, empty, matched wrong history and budget-matched analytic calibration. Include current-prefix versus retained history if claiming cross-episode memory. Match probe cost, opening state, motor proposal and horizon. Use 100 fresh UR5e placements for the planned task-specific test. Additional independent tasks and robot families are needed for a broad transfer claim. [Critical review](REVIEW.md) |

## First two experiments

1. Reuse the proven command-frame manipulation as a positive control. Freeze the original source PaliGemma checkpoint. On separate fresh source layouts, compare the correct inverse, wrong inverse, identity and best fixed correction. Keep the residual action family and saturation identical. If oracle headroom and opposite required corrections are visible, freeze the pilot protocol and its evaluation splits. The stronger source-SFT checkpoint supplies a prespecified replication once the comparison is interpretable. A command-frame experiment qualifies the experimental plumbing. Claims about kinematics or contact require dedicated tests.
2. Establish the identity path and run the nominal/shifted comparison together. Preselect the abstention threshold and the tolerated nominal harm on source development data. A candidate tolerance is five percentage points, subject to the scientific cost of breaking a successful trial. Report per-arm paired losses and gains with intervals, clustered when support histories or robot families repeat. In an earlier four-start π0.5 pilot, raw was 4/4 and correct-history adaptation was 2/4. That observation motivates the control. It does not estimate a population harm rate. [Earlier paired experiment](../libero-crossarm-20261120-r1/RESULT.md)

The privileged-versus-public comparison follows an established system-identification design. The proposed contribution here would be evidence about when public history helps a frozen manipulation policy, when a simple estimator is sufficient, and when the learner should abstain. [Yu et al., RSS](https://www.roboticsproceedings.org/rss13/p48.pdf) · [Kumar et al., RSS](https://arxiv.org/abs/2107.04034)
