# S18 alters wrist position while preserving measured motion on matched resets

All eight BASE/S18 pairs started from identical simulator-state fingerprints and completed the same ten probe controls. At reset the publicly reported wrist position was offset by approximately **(+7.5, −6.0, +4.5) cm** in S18 on every task. Across the 80 matched control transitions the largest difference between BASE and S18 wrist displacements was **1.21 × 10⁻⁷ m** or less. This matches the release implementation, which adds a constant offset to the reported end-effector positions. Taking consecutive differences removes it up to floating-point rounding. For the frozen `pi05_libero` motor used in this campaign, the checked OpenPI configuration disables discrete state input and extra delta action conversion. The π0.5 action expert has no continuous state token. With images, prompt and sampling noise held fixed, the additive numeric state offset therefore has no route into the native actions. A separate reader that sees absolute robot state or an independent visual reference could consume other evidence. This experiment measured proprioception on development resets with cameras disabled and did not score manipulation success. The constructed actuator reversal is a different mechanism.
