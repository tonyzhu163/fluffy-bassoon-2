## Controller and measurement contract

The same mounted seven-hinge Panda and one-command PandaGripper run at 20 Hz in both constructors. OSC_POSE accepts a world-frame grip-site translation and left-composed axis-angle increment followed by the gripper. The component ranges per command are ±0.05 m and ±0.5 rad. JOINT_POSITION uses its stock fixed-impedance servo, kp 50 and critical damping. Its seven normalized entries each specify up to ±0.05 rad relative to the current joint position, followed by the same gripper command. Both input boxes are checked before every step. Gripper commands use the sign and value from the bounded VLA output.

Initialize both native environments from the identical released Panda row. Use the released ten-control OSC settling procedure once. Restore the full MuJoCo integration state, gripper accumulator, scene and sensor-clock phase into the query branches. Check equal object/fixture states and equal first public observations. The Jacobian decoder thereafter reads ordered joint encoders, a known fixed-base kinematic model, joint bounds and the grip-site transform in the world frame. It uses a separate FK scratch state with only the arm joints populated. The motor still sees the ordinary two RGB views, TCP position, hand quaternion converted to axis-angle, finger positions and the instruction. A hand-link orientation and grip-site orientation have the same world-frame rotational increment for a rigid tool.

The 6-by-7 geometric Jacobian maps joint velocity to world linear and angular velocity. Solve bounded least squares for the normalized joint action, with both the advertised controller bounds and the model joint limits. The residual uses the source controller's six component scales to nondimensionalize the Cartesian error. A 0.02 damping term regularizes the dimensionless solve. The fixed local response fit instead estimates two matrices from signed half-range native pulses and zero controls, using measured world-frame TCP motion. It uses a single separate practice layout under both known interfaces, reset to the same posture per pulse. Its damping is 0.02 times the target matrix's largest singular value. Neither decoder reads query object state, reward, future actions or contact forces. Calibration with independently reset pulses requires more access than a single uninterrupted passive tape.

Motion probes fork eight evenly spaced states on each successful source tape. They measure a single 50 ms physical response at a synchronized endpoint. The local oracle additionally measures the achieved source motion and a fresh joint pulse basis at that exact query state. It can examine counterfactual outcomes and is an approximate inverse, with no guarantee of minimum realized error. The trajectory oracle instead gets the entire successful source joint path and a gripper schedule. The deployable decoders receive neither privilege. The replay trajectories under JOINT_POSITION are open-loop in policy commands and closed-loop in the joint decoder. Failure to receive reward before the recorded tape ends is censored there; both privileged trajectory schedules run to the native horizon or success.

The prior xArm6 experiment's frozen_task_policy reads native object and goal coordinates and chooses gripper timing in code. Its 16/24 continuous-angle oracle measures correction of an imposed interface on that scripted motor. A separate older WidowX ManiSkill RL/SFT motor has native competence on its own object benchmark (RL 82.8% success-once on 500 episodes). Neither result establishes frozen-checkpoint competence on the xArm6 task. The related cross-controller history study jointly trained its policy and context encoder. This experiment isolates inference-time conversion of an already competent frozen motor.
