# Can two zero-reward failures at the same goal require different motor corrections?

The bowl and bottle destination studies supplied the feedback rule. This pilot holds the goal fixed and compares released D17 (grasp disruption) with D18 (drop during transport) in the Goal 2 bottle world. Use the six previous development poses 24–29, both cabinet and rack prompts, and the same nominal practice commands in each fault. Native rewards are the corresponding published goal predicates over 300 controls. For each practice pose, use the next pose cyclically as the shared query reset under the same persistent condition. This is custom development scoring. The D18 outcomes are known; the crossed query actions and D17 outcomes are new.

Run both conditions with the same menu of three possible corrections for each pose and destination. The default is the independent nominal query tape. The grasp retry retreats with open jaws from the first sustained closure, returns to the pregrasp waypoint and reissues the nominal remainder. The transport retry uses the archived commands from the frozen motor replanning after D18 on that query pose. This makes it an optimistic, pose-specific candidate. No branch reads the actual condition ID to choose a command. Preserve the motor budget, commands and fixed goal within each comparison. Record success at any step, terminal success, actual native event, wall time and controls.

A primary qualifying pair needs two verified triggered failed practices, a shared query reset, at least one successful continuation for each condition and no continuation successful in both. Test terminal equality on unmasked full 96 × 96 RGB from both cameras and separately on wrist/jaw state. Report continuous camera separation as well. Distinct final images alone do not establish that a practical reader can exploit them. As a complementary test, fit a sensor-to-retry reader using only outcomes at other pose IDs, excluding trials sharing either the practice or query pose. Compare terminal pixels, terminal robot state, short trajectory, fixed action and reassigned history when the physical menu distinguishes the two conditions. Zero qualifying cases is evidence about the benchmark and action menu. It cannot establish an incapacity to meta-learn.

Independent archive checks will document earlier endpoint and action coverage. Use Baige CPU software rendering, at most six workers, zero GPU-hours, and close after the physical feasibility result. All seeds are 18180100 + pose for physics. Keep official held-out tasks reserved.
