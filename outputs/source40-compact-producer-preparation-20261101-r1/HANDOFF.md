## Narrow source integration

`vla_source40_corpus.main` gains one flag, `--compact-history-evidence`, default
OFF. The false branch keeps the original source contract/index/trace fields,
unwrapped chooser, update rule, cases, rewards, failures, warmup, features and
full-recovery/case-publication cadence. The true branch calls the new
`vla_source40_compact_evidence.CompactHistoryEvidence` around the same existing
reset/choose/episode/SGD/trace operations. No new learner or collector framework.

Static AST counts match the parent collector for `motor.infer` (2),
`run_episode` (1), `wrapped.finish_episode` (1), `learner.save` (2), and
`motor.feature_encoder.qualify` (1). This is a source review, **not** runtime
parity evidence. The synthetic integration regression is written to compare
actual chooser requests, flat raw data, actions, rewards, updates, costs,
feature/motor calls and full-save cadence, with explicit fake runtime/model
substitutions. It has not run and cannot qualify a scientific source run.

Fresh opt-in contracts record `compact_history_evidence=PROTOCOL`. Existing
contract equality rejects turning the flag on for an old resume or off for an
opt-in resume. Legacy migration continuations cannot enable it. Same-contract
resumes validate the original compact receipt cursor, canonical actor state,
actual replay/update counts and RNGs before another training episode. No old
identity is synthesized and no new source role is assigned.

## Original compact evidence

- Full acting state uses the EXISTING canonical helper:
  `vla_libero.structure_digest(serialization.to_state_dict(full actor TrainState))`.
  Every serialized actor collection/state is covered; params-only SHA remains a
  separate diagnostic. Source contract/code/recipe/preprocessing binds policy
  configuration; actor encoder/normalization state is included. Student shared
  prefix4104 and TRAIN-only normalization are untouched.
- Before every actual choice, the wrapper checks the same full state and actual
  update/replay clocks, records private RNG content identity, then calls the
  original chooser exactly once and returns its original noise unchanged.
- Gaussian warmup explicitly records `actor_not_used=true`, null actor hashes,
  original standard-normal32/tied-H10 configuration, contract/seed identity and
  actual RNG state. Warmup and failed episodes remain in their original order.
- Compact pickles record actual sampler, agent, global NumPy/Python and native
  motor RNG at episode start, after physical behavior/before SGD, and after the
  original complete SGD burst. Metadata obtains states without RNG draws.
- Original reset journal references and before/pre-SGD/after counts, replay
  counts, durations and observed update metrics are bound in the raw episode
  payload and immutable episode JSON. Pre-action evidence is also in the
  existing pre-learning decision-journal `pending` payload.
- Opt-in raw episode filenames include the unique attempt identity. This keeps
  interrupted original trace references intact instead of reusing their paths.
  There is still one flat raw trace per complete episode. Legacy names stay
  unchanged. Orphan attempt evidence remains outside committed chronology.
- Existing full-recovery progress receipts remain the authoritative cursor.
  Compact metadata can be regenerated from those original references on resume;
  it cannot pad an interrupted episode or retrofit a legacy history.
- Live chronology is a rolling metadata pointer only. Final
  `compact-history/chronology-complete.json` is immutable and binds original
  committed episodes. No per-episode full learner/replay snapshots are added;
  before/after full refs remain optional and null in producer output.

## Explicit V2 ABI change

Adapter declaration/assembly formats become
`source40_independent_lineage_declaration_v2` and
`source40_independent_lineage_assembly_v2`. Producer/chronology format is
`source40_compact_history_evidence_v2`. The seven-array NPZ and existing history
trainer formats do not change. Params-only V1 evidence is not upgraded or
treated as equivalent; the original a5f7 package remains identifiable by commit.

Public adapter function and declaration/binding keys stay as in a5f7, with:

- Original source contract must bind the opt-in V2 protocol. Binding
  `chronology` must equal the original source index's final
  `compact_history_evidence` reference.
- `behavior_identity` adds required `actor_state_sha256`, `actor_state_scope`,
  and `source_contract_sha256`, alongside kind/actor-not-used/params/sampler
  fields. Original raw payload and each actual action row bind that identity.
- Original raw payload adds `actor_state_after_sha256`, `rng_pre_sgd_ref`,
  `reset_ref`, `compact_episode_clocks`, and actual `compact_update_metrics`.
  Existing before/after RNG and params fields remain distinct.
- Chronology records add `actor_state_after_sha256`, `rng_pre_sgd`, `reset_ref`,
  and `clocks`. The adapter checks original raw agreement, typed warmup, full
  actor continuity, reset identity, actual update/replay clocks and final full
  recovery. Original raw replay contents must match the final recovery.
- DPT teacher qualification additionally binds `actor_state_sha256` to the
  exact full TRAIN actor state, while retaining its pure params diagnostic.
  Frozen label-state checks use the existing canonical helper, not serialization
  byte ordering. TRAIN and VAL still use the same qualified TRAIN teacher.
